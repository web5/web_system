# 风格原型卡 · Style Profiles

> 写作能被模仿的前提，是把"他写得好"翻译成**招式**。
> 本文件的每一张卡都遵守同一结构：**人设 → 招式 → 结构模板 → 标志动作 → 可观测判据 → 别学什么**。
> 「可观测判据」是重点：它必须能在一篇成稿里被数出来，否则只是形容词。

调研时间：2026-09-03 · 维护人：techdog

---

## 〇、先看结论：三个可迁移的能力源

模仿不是抄一个人，是**拼三种能力**。一个人身上往往只有一种强：

| 能力源 | 解决什么 | 最强提供者 | 你的可迁移度 |
|---|---|---|---|
| **骨架** | 读者读得下去、跟得住 | 九边 | 高（纯结构，无身份依赖） |
| **刀锋** | 读者觉得"你说到点子上了" | 半佛仙人 | 中高（需要内行信息） |
| **底色** | 读者觉得"这个人值得长期关注" | 池建强 | 中（需要真实经历打底） |

**只学骨架 = 顺滑但没记性。只学刀锋 = 犀利但招黑。只学底色 = 温润但没传播。**
三者拼起来才是"博主"而非"写手"。

## 一、主模仿对象（博学高 · 锐利度高）

### 1. 半佛仙人 —— 从利益博弈解构一切

**一句话人设**：风控从业者下场，把内行人才看得见的坑，写成外行也读得爽的长文。

**招式拆解**
1. **利益解构**：任何事都问一句"谁在出钱、谁在受益、谁在付代价"。复杂规则被翻译成大白话的博弈。
2. **内行视角**：写"普通人没资格看到的事情"——采购回扣、加盟套路、灰黑产链条。信息差本身就是价值。
3. **吹哨人姿态**：不为骂而骂，而是"能帮一个是一个"。读者留言"因为你我没被骗"是他的核心正反馈。
4. **主动放弃爆款规律**：超长文、无图、不排版、错字多——他赌的是"读者看烂了标题党之后的报复性反弹"。

**结构模板**
```
抛出反常识结论（一句）
  → 拆利益链条（谁出钱 / 谁受益 / 谁付代价）
  → 内行细节轰炸（3-5 个外行不知道的具体环节）
  → 落到"你该怎么办"（可执行）
  → 收尾一句狠的
```

**标志动作**
- 用具体钱数代替形容词："采购，永远是最肥的，这是一个真理"
- 揭机制不揭情绪：不骂资本，而是算清楚它怎么赚钱
- 标题直接给结论：《再坚持一下，你的奶茶店马上破产》

**可观测判据（自检）**
- [ ] 全文至少点名 **3 个具体利益角色**（不是"某些人""资本")
- [ ] 至少 **1 处外行不知道的环节细节**（数字、流程、行话的解释）
- [ ] 结尾给了**可执行动作**，不是情绪宣泄

**别学什么**
- ❌ 他的"无排版超长文"是**结果不是方法**——他有 4000 字/篇的产能和风控一线素材，你没有
- ❌ 别学"起底黑产"这条赛道，你没有他的信源和法务承受力
- ❌ 别学他"不查证就开炮"的部分

### 2. 老蒋巨靠谱（蒋松筠） —— 媒体人的查证法

**一句话人设**：虎嗅/创业邦出身的商业记者裸辞做 B 站，20 分钟长视频，粗糙但真诚，信息密度极高。

**招式拆解**
1. **采访 + 查证 + 论述**：传统媒体工作流，先问人、再核数据、最后下判断。这是他与"观点先行"类博主的根本分野。
2. **粗糙美学**：不采购设备、不追求视觉，把手机怼脸拍最想说的东西。省下的力气全砸在内容密度上。
3. **从财经评论拓到社会观察**：核心能力不是财经知识，是**选题敏感度 + 信息查证能力 + 观点提炼能力**这三件套。

**结构模板**
```
我要回答一个问题（明确设问）
  → 我先去查了什么 / 问了谁（过程可见）
  → 一层层排除错误答案
  → 我现在的判断是……（含不确定性标注）
  → 这个判断对你意味着什么
```

**标志动作**
- **过程可见**：告诉读者"我查了哪些资料、问了哪几个人"
- 承认自己判断的边界："这一点我可能错了，因为……"
- 用理工科逻辑框架（南京大学 IT 背景）组织信息

**可观测判据（自检）**
- [ ] 文中明确出现 **"我查了/问了/看了"** 的过程描述 ≥1 处
- [ ] 数据有**出处**，不是"据研究表明"
- [ ] 至少 **1 处标注了判断的不确定性**

**别学什么**
- ❌ 别在公众号上学他的"粗糙"——文字载体没有镜头人格兜底，粗糙就是错字连篇
- ❌ 他的 20 分钟长视频节奏不能直接搬到图文（段落长度和节奏感完全不同）

### 3. 傅盛 —— 亲历者预判

**一句话人设**：上市公司 CEO 亲自下场当自己产品的头号用户，用"我干了 14 天"代替"我认为"。

**招式拆解**
1. **亲历即论据**：滑雪摔伤卧床 14 天，跟 AI Agent 发了 1157 条消息、22 万字，公众号从年更十几篇变日更，半个月涨粉 5 万。**他不说"AI 很强"，他说"我 14 天做了什么"。**
2. **预判优先于追热点**：他反复强调"这不是运气好抓住了机会，我从去年就判断桌面版 Agent 会出现"——**预判是人格资产，追热点不是**。
3. **把失败和翻车写进去**：Agent 忘了提醒航班、报告写"正常"但 22 小时没干活、直播现场网站挂了当场修。真实感来自不遮丑。
4. **细节密度**：Day 1-14 逐日记流水账，但每一天都有一个"aha moment"。

**结构模板**
```
我判断 X 会发生（含判断时间点，可回溯）
  → 于是我用 N 天亲自做了什么
  → 中间翻了哪些车（不遮丑）
  → 我做成了什么（具体数字）
  → 这对你意味着什么 / 你现在该做什么
```

**标志动作**
- 用**可回溯的时间戳**证明不是马后炮："去年我们就认为……"
- 用**具体数字**代替程度副词：1157 条消息 / 22 万字 / 40+ Skills / 611 条拜年 / 0 失败
- 金句来自实践而非修辞："虾如其主，这只虾的水平和你的水平高度相关"

**可观测判据（自检）**
- [ ] 有 **≥1 个可回溯的判断时间点**（能证明不是马后炮）
- [ ] 有 **≥3 个具体数字**（条数 / 字数 / 天数 / 金额 / 百分比）
- [ ] 有 **≥1 处翻车或失败**的真实记录

**别学什么**
- ❌ 他的"蹭热点式流量打法"（P 猴图、游戏直播、爬车顶）是**双刃剑**：界面新闻的批评很准——"流量来的快，但黏不住"，且个人流量与公司业务闭环断裂
- ❌ 别把 CEO 身份当模板——你是独立开发者，**你的亲历是"我一个人做产品"，同样成立但要换素材**

## 二、底色与素材源（博学高 · 观点温润）

### 4. 池建强（MacTalk） —— 技术人文

**一句话人设**：70 后程序员，写 Mac 起家却不止于 Mac，"科技与人文结合，文风有趣，又增加了一点力量"。

**招式拆解**
1. **技术 + 人文双线**：前期推 Mac 技巧太干，就在前面加自己的思考或小故事——结果这部分越写越多，成了主体。**技术是他的人设背书，人文是他的传播面。**
2. **写身边的人**：他明确说过，内容里有"我身边的人和他们的故事"，"记录了这个时代的某个剪影"。人物是他最常用的容器。
3. **对文字本身有要求**：他会刻意读写作的书，看文学作品时关注"结构、文法、用词和节奏"。这在技术博主里极罕见。
4. **池之以恒**：2012 年末开号，写到今天。持续输出本身就是人格资产。

**结构模板**
```
一个具体的人 / 场景 / 小事（画面感开场）
  → 从这件小事里我看出……
  → 技术或行业的某个观察
  → 拉回到人的处境
  → 收束在一句有余味的话（不喊口号）
```

**标志动作**
- **用人物承载观点**：不直接说理，先给一个活人
- 短句、轻节奏、口语化，但句子是打磨过的
- 收尾克制，不用感叹号堆情绪

**可观测判据（自检）**
- [ ] 开篇 **200 字内有具体的人或场景**（不是概念开场）
- [ ] 全文至少 **1 处"技术/行业观察"与"人的处境"的勾连**
- [ ] 结尾 **不是总结陈词**，是留白或余味

**别学什么**
- ❌ 别把"人文"写成抒情——他的力量来自克制
- ❌ 他的 Mac/Apple 素材已经过时，不要模仿题材，模仿**结构**

### 5. 九边 —— 隐而不露的逻辑

**一句话人设**：程序员出身的公司中层，把历史、经济、地理、国际政治揉进唠嗑式的口语里，"像午后树荫下跟一个见闻广博的大哥聊天"。

**招式拆解**
1. **先下结论，再由浅入深**（卢诗翰也用这招，但九边的论据更扎实）。
2. **隐而不露的逻辑**：文章没有明显的总分总或黄金三点，逻辑像剥洋葱层层推进，**藏在口语化文字里，过渡自然，读来行云流水**。这是他最值钱的能力。
3. **情绪藏在细节里**：不说"那段时间我过得特别苦"，而说"经常赶最后一班地铁，靠着扶手就能睡着，到站了还得旁边人喊一声"。**写具体小事，不写形容词。**
4. **持续学习 + 人脉素材**：写电动车那篇查了几十万字材料，还专门咨询了十几个行业内资深从业者。**一手信源是他的护城河。**
5. **长文但不累**：读完十分钟不觉得无聊，因为段落短小、节奏明快、始终围绕一个主题。

**结构模板**（这是本文档最值得直接套用的骨架）
```
现象 / 故事（口语化开场，第一人称）
  → 表面原因（大家通常以为是这个）
  → 本质原因（其实是因为这个，用历史/地理/经济类比）
  → 结论（所以……）
  → 启示（对读者个人意味着什么 / 该怎么做）
```

**标志动作**
- 用**生活化比喻**解释抽象概念：把地缘政治类比成人际关系
- 大量使用"说白了""那玩意儿"等口语连接词降低阅读门槛
- 素材跨领域：一个论点下同时出现历史事件、国外案例、行业数据、读者亲身经历

**可观测判据（自检）**
- [ ] 走完了完整的 **五段推进**（现象→表面→本质→结论→启示），"表面原因"这一段**不能省**——省了就没有"剥洋葱"的感觉
- [ ] 至少有 **1 个跨领域类比**（历史 / 地理 / 经济 / 国际）
- [ ] 情绪段落用**具体小事**而非形容词

**别学什么**
- ❌ 他的核心竞争力是**长期积累 + 人脉信源**，"学不来他的内容"——你只能学结构，不能学他的素材密度
- ❌ 别学他后期的"追热点嫌疑"和变慢的更新

### 6. 阮一峰 —— 守夜人

**一句话人设**：2003 年写博客，2018 年开周刊，每周五必到。把西方程序员思想翻译成中国人读得懂的语言。

**招式拆解**
1. **通俗易懂是核心能力**：不是编程写得多好，而是**能把复杂的东西讲明白**。短段落、多分段，一句话能说清绝不用两句。
2. **持续到成为确定性**：在框架每年洗牌、风口每周换人的行业里，"每周五他一定会出现"本身就是价值——**读者订阅的是确定性，不是内容**。
3. **开放不设墙**：全部开源，不做付费订阅。

**结构模板**
```
这周有件值得说的事
  → 它是什么（讲明白，不炫技）
  → 为什么值得关注
  → 我的看法（简短，不展开）
```

**可观测判据（自检）**
- [ ] 单段 ≤ 3 行
- [ ] 每个术语第一次出现时**有解释或类比**
- [ ] 有明确的**发布节奏承诺**（周几更新，且真的做到）

**别学什么**
- ❌ **他有信息密度但没有观点密度**——这是他最大的局限。你的目标是"有判断的博主"，不能停在"信息搬运工"
- ❌ 别学他完全不表态

## 三、借招，不学整体

### 7. 卢诗翰 —— 造词与观点先行（高风险）

**一句话人设**：泛财经流量作者，擅长用创造性视角（甚至自造单位）把复杂商业问题讲通俗。

**招式拆解**
1. **造词即传播**：为了说明流量明星刷数据，他自创了"京"这个数据单位（《刷数据时代：不刷到 500 京，都不好意思打招呼》）。**一个词顶一万字。**
2. **先下结论再由浅入深**：标题即结论，正文是论证。
3. **不放过任何可蹭的热点**：把顶流元素（肖战、阅文）塞进标题和关键论点，让不同立场的读者都能从中找论据，从而破圈。
4. **他自己也承认长文无效**：近年在主动缩减篇幅，因为"你几万字的长文就是会被对面几个字总结碾成渣"——**现实案例的高度抽象化**才是传播力。

**可观测判据（自检）**
- [ ] 是否为本文的**核心机制造了一个可传播的词**
- [ ] 标题是否**直接给结论**（不是设问悬念）

**别学什么 —— 这条最重要**
- ⚠️ **观点先行的反噬**：《腾讯的背水一战》刷屏后不久，腾讯 2020 Q1 财报收入 1080.65 亿超预期、净利润同比增长 6%——"背水一战"被财报当场打脸。**观点跑在证据前面，涨粉快，掉公信力更快。**
- ⚠️ 有评论认为他"拼凑火的要素 + 找高大上理由 + 说已存在的现象即将发生"，即**"预言家"姿态的安慰剂**。
- ⚠️ 你的专家定义里已有红线：不杜撰、不编数据。**卢诗翰的"造词"可以学，"造势"不能学。**

### 8. 周鸿祎 —— 流量嗅觉（反面样本价值大于模仿价值）

**一句话人设**：从"红衣大炮"转型"红衣大叔"，一年发 1400+ 条视频，把企业家 IP 当成公司义务来做。

**招式拆解（可借的部分）**
1. **极致的接地气**：考驾照让网友推荐驾校、拍卖自己的迈巴赫（990 万成交）、爬车顶、拍短剧。**他懂如何把握网友心理。**
2. **系列化发酵**：卖车→看车→买车→学驾照，每个主题都是"预热 + 续集 + 持续发酵"的一条龙，**同一事件榨出多次热搜**。
3. **观点量产**：日更怼脸视频，三句话一个观点。

**可观测判据**
- [ ] 一个热点是否被拆成**系列**而非单篇

**别学什么 —— 界面新闻的批评几乎每一条都成立**
- ⚠️ **内容风格太随意**：怼脸直拍、镜头晃动、剪辑生硬，被怀疑读稿子。在短视频平台极不利于涨粉。
- ⚠️ **爆点太依赖外部热点**：卖迈巴赫、车展、互联网大会——每次涨粉曲线背后都有公共事件加持，而讲自己产品的内容热度明显掉档。**"内容搬砖工，连夜拍短剧都要自己写剧本"。**
- ⚠️ **离闭环太远**：雷军五句话必带产品（产品即内容），周鸿祎三句话一个观点但用户不知道 360 在卖什么。**流量挂在他个人账号上，转化不成公司业务。**
- ⚠️ 结论：**流量来的快，黏不住。** 对你（独立开发者、有自己产品）来说这是最该避开的坑——**你的内容必须能回到你的产品。**

## 四、只借共鸣，不做主线

### 9. 李尚龙 —— 金句与痛点

**一句话人设**：百万畅销书作家，文字犀利直击年轻人"伪努力"的痛点，故事化载体，清晨四千字日课。

**招式拆解**
1. **爆款三要点**（他自己总结）：符合碎片化阅读习惯 / 极短篇幅把事讲清 / **有没有写跟大家有关的事**。
2. **故事为载体，不说教**：用真实案例和故事承载观点，语言通俗易懂。
3. **金句密度**：《你只是看起来很努力》《你所谓的稳定，不过是在浪费生命》——**书名本身就是可传播的观点单位**。
4. **清晨四千字**：坚持每天写四千字，即使不以发表为目的。

**可观测判据**
- [ ] 是否有 **≥1 句可脱离文章独立传播的金句**
- [ ] 观点是否**装在故事里**而非直接陈述

**别学什么**
- ❌ **"清醒励志"是消耗品**：戳痛点 → 给安慰 → 无沉淀。读者读完感觉很好，第二天什么都没变。
- ❌ 容易滑向"伪深度"：用犀利的语气包装常识。
- ❌ 他的读者群是迷茫期年轻人，**与你的读者（开发者 / AI 从业者 / 投资人）重叠度低**。

## 五、附录：借招库（只用一招，不模仿整体）

| 人 | 只借这一招 | 怎么用 |
|---|---|---|
| **六神磊磊** | 借壳说事 | 找一个读者熟悉的外壳（金庸/唐诗/某部经典），装进当下的事。**规则：要讲读者知识边界外的东西，必须从他熟悉的人或物讲起**——"卢植有个徒弟，叫刘备" |
| **和菜头** | 比喻 + 极短标题 | 标题不超过 12 个字（《我恨 PPT》《又被举报了》）；比喻要有历史/生活厚度（"人生是用一把破筛子舀水"） |
| **小Lin说** | 故事化 + 数据硬核 | 脚本结构：痛点提问 → 故事引入 → 数据论证 → 类比拆解 → 行动建议 |
| **孟岩 / 张潇雨** | 真诚即方法 | 孟岩公开实盘"亏给你看"，每周公布 400 万仓位的操作。**张潇雨的建议："你只要写自己真实的、有感受的内容就好了。"** |
| **傅盛（多选）** | 把翻车写进去 | 不遮丑是最低成本的真实感 |

## 六、推荐套餐（选一个先跑三个月）

### 套餐 A · 技术人文 + 利益解构 + 唠嗑逻辑（推荐，默认）

**适合**：科技 / AI / 独立开发者话题，读者是有判断力的从业者。

| 位置 | 提供者 | 比重 |
|---|---|---|
| 开篇 200 字 | 池建强 | 具体的人或场景切入，口语、克制、有余味 |
| 主体骨架 | 九边 | 现象 → 表面原因 → 本质原因 → 结论 → 启示 |
| 观点刀锋 | 半佛仙人 | 至少 1 处利益溯源：谁出钱 / 谁受益 / 谁付代价 |
| 证据密度 | 老蒋巨靠谱 | 至少 1 处"我查了 / 问了"的过程可见 |
| 结尾 | 池建强 | 留白或余味，不是总结陈词 |

### 套餐 B · 一线亲历 + 查证 + 持续

**适合**：你有真实项目/产品在做，想用内容反推产品。

| 位置 | 提供者 | 比重 |
|---|---|---|
| 主线 | 傅盛 | 我判断 X（含回溯时间点）→ 我用 N 天做了 → 翻车 → 数字成果 |
| 查证 | 老蒋巨靠谱 | 过程可见 + 标注不确定性 |
| 节奏 | 阮一峰 | 固定周几更新，把确定性做成资产 |

### 套餐 C · 大众共鸣 + 唠嗑骨架（谨慎）

**适合**：想破圈到非技术读者。**风险：容易滑向无沉淀。**

| 位置 | 提供者 | 比重 |
|---|---|---|
| 骨架 | 九边 | 现象 → 本质 → 启示 |
| 情绪 | 李尚龙 | 故事载体 + 金句 |

> ⚠️ 套餐 C 必须额外加一条硬约束：**每篇至少 1 个具体数字 + 1 个可验证来源**，否则会退化成鸡汤。

## 七、融合配方的落地校验

写完一篇，按这个清单核。**任何一条不过，就不许交付。**

| # | 检查项 | 来源 | 判据 |
|---|---|---|---|
| 1 | 开篇 200 字内有具体的人或场景 | 池建强 | 概念开场 = FAIL |
| 2 | 走完五段推进，且"表面原因"段未省略 | 九边 | 缺段 = FAIL |
| 3 | 全文点名 ≥3 个具体利益角色 | 半佛仙人 | 用"某些人/资本" = FAIL |
| 4 | 有 ≥1 处"我查了/问了"的过程可见 | 老蒋巨靠谱 | 无过程 = FAIL |
| 5 | 有 ≥3 个具体数字 | 傅盛 | 数字 <3 = FAIL |
| 6 | 有 ≥1 句可独立传播的金句 | 李尚龙 | 无 = WARN |
| 7 | 是否有可传播的新词 | 卢诗翰 | 无 = WARN（不阻塞） |
| 8 | 结尾不是总结陈词 | 池建强 | 喊口号/总结 = FAIL |
| 9 | 无"震惊/速看"标题党、无"随着…的发展"八股 | 通用红线 | 命中 = FAIL |

## 八、反面清单（明确不模仿）

| 不模仿 | 原因 |
|---|---|
| 周鸿祎的"追热点式流量" | 流量来的快黏不住，且与自己的产品闭环断裂 |
| 卢诗翰的"观点先行" | 会被后续事实打脸（腾讯背水一战 vs Q1 财报），公信力是慢变量、毁得快 |
| 半佛的"超长无排版" | 那是产能和素材堆出来的结果，不是方法 |
| 李尚龙的"清醒励志" | 读者读完感觉很好，第二天什么都没变 |
| 阮一峰的"只搬运不表态" | 信息密度高但观点密度为零，成不了"博主"只能当"信源" |
