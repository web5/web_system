# 锐利观点与共鸣工程

> **一句话**：读者关注的不是那条新闻，而是**你的眼睛**。新闻 48 小时就过期，判断框架不会——这才是博主的人格资产。

## 核心公式

```
锐利观点 = 反常识的判断 + 别人没看到的因果链 + 可验证的证据 + 读者的利益关联
共鸣     = 说出了读者隐约感到、却说不出口的那句话
关注     = 读者决定"以后还借这双眼睛看世界"
```

**认知差三层**（观点必须落在第三层）：

| 层 | 内容 | 谁停在这 | 认知增量 |
|---|---|---|---|
| 事实层 | 发生了什么 | 大众 | 零 |
| 归因层 | 为什么是现在、谁在获利 | 内行 | 有，但不可传播 |
| **判断层** | **所以谁会怎样、你该怎么办** | **你** | **观点在这里** |

只写到事实层 = 新闻搬运；停在归因层 = 行业分析；**落到判断层才有观点**。

## 一、观点怎么生产（七种思维动作）

拿到一个热点，**至少跑 2 个动作**，产出候选观点再择优。每个动作附句式模板，直接套。

**1. 归因下沉** — 别人说"发生了什么"，你问"为什么是现在"
> 三层追问：为什么是现在？为什么是它而不是别人？谁受益？
> 句式：`表面上是 A，但真正让它发生在今天的，是 B 发生了变化。`

**2. 反共识** — 主流说法成立的前提，往往已经失效
> 步骤：列主流说法 → 找出它依赖的前提 → 证明前提已变 → 给新判断
> 句式：`大家都说 A。但 A 成立的前提是 B，而 B 上个月刚被 X 打破。`

**3. 利益溯源（Cui bono）** — 不问"他说了什么"，问"他为什么现在说"
> 句式：`先别急着评价这句话对不对，先问一句：他为什么是今天说，说给谁听，想要什么。`

**4. 代价显影** — 每个趋势都有被藏起来的成本，把它挖出来
> 句式：`所有人都在算这件事省了多少，没人算这笔账最后由谁付。`

**5. 历史类比** — 找结构相同的上一次，看它怎么收场
> 句式：`这不是第一次。2012 年的 X 是同一个结构，当时的收场是 Y。`
> 注意：类比要**比结构不比表面**，否则是廉价的比喻。

**6. 时间尺度切换** — 拉远看荒谬，拉近看关键
> 拉远：`五年后回头看今天这场争论，大概会像我们现在看 2015 年的 O2O。`
> 拉近：`真正决定胜负的是那 72 小时里的一个动作。`

**7. 反身视角** — 先带读者站到对面，再拉回来
> 句式：`如果你站在他们的位置上，这个决定其实完全合理。问题是——你不在那个位置上。`

## 二、博学底座（在不熟的领域也能下判断）

**博学的定义不是"知道得多"，是"思维模型可迁移"。** 判据：同一个话题，能否调用 **≥2 个不同领域的模型**交叉验证。

**下判断前的最小知识量（三件，缺一不下判断）**：

| 层 | 必须回答 | 判据 |
|---|---|---|
| 事实层 | 到底发生了什么 | 有**具体数字 / 名字 / 时间**，不是"据说""大幅" |
| 利益层 | 谁出钱、谁受益、谁承担代价 | 能点名到角色（不是"某些人"） |
| 历史层 | 同类结构上一次怎么收场 | 至少 1 个可比案例，能说清结构相同点 |

**常用可迁移模型**（按需要取用）：成本结构 · 激励与委托代理 · 技术扩散曲线 · 网络效应 · 路径依赖 · 沉没成本 · 边际收益递减 · 信息不对称 · 规模不经济 · 组织惯性。

**借脑原则**：找不到领域专家时，就去找"上一次发生同样结构的事"——历史案例是最好的免费专家。

**禁区**：知识量不够时，写「以下是我的推测，依据是 X，证据强度：弱」——**标注不确定，不装懂**。装懂一次，人设资产清零。

## 三、共鸣工程（怎么让读者觉得"与我有关"）

**共鸣的本质是 Latent Pain 显性化**——读者隐约感到不安，但说不清楚，你替他说出来了。

四个动作：

1. **命名**：给现象起个名字（"XX 陷阱""XX 幻觉""假装忙碌税"）。**命名权就是传播力**——有了名字，读者才能引用你。
2. **场景锚定**：把抽象趋势落到具体时刻。
   > 不说"AI 正在改变工作方式"，说"周一早上你打开后台，发现上周那个要写一天的报表，现在已经在那儿了"。
3. **利益映射**：明确指出触动读者的哪一条 —— **钱 / 时间 / 职业安全感 / 身份认同**。四选一，不许全选（全选 = 没选）。
4. **反鸡汤**：不给情绪价值，给**判断工具**。读者带走的是"下次我该怎么判断"，不是"我被安慰了"。

**注意**：共鸣 ≠ 附和。附和读者的既有立场只换来点赞，说出他没想到的才换来关注。

## 四、质检：真锐利 vs 假锐利

### 四问质检（每篇必过，缺一即重写）

| # | 问题 | 通过标准 |
|---|---|---|
| 1 | **可证伪吗？** | 能写出"如果 X 发生，我就错了"——写不出就不是判断，是感慨 |
| 2 | **意外吗？** | 不在主流答案的**前两个**之内（前两个 = 大家都想得到 = 不锐利） |
| 3 | **有解释力吗？** | 能解释主流说法解释不了的那个现象 |
| 4 | **与我有关吗？** | 读者的钱/时间/职业/身份，明确命中一条 |

### 反向测试（最硬的一招）

> **把你的主张取反，如果反命题同样说得通、同样好听 → 这是废话，重写。**

例：「技术是中性的，关键看怎么用」取反 →「技术不是中性的，它自带倾向」——两句都成立 = 零信息量。

### 反例清单（假锐利的六种伪装）

| 伪装 | 特征 | 为什么不算 |
|---|---|---|
| 情绪替代理性 | "太离谱了""细思极恐""令人深思" | 情绪不是认知，零增量 |
| 正确的废话 | "机遇与挑战并存""关键看怎么用" | 取反也成立，不可证伪 |
| 马后炮 | "我早就说过会这样" | 无预测，不担风险 |
| 只有叙述 | 通篇讲"发生了什么"，结尾一句感慨 | 停在事实层 |
| 为反而反 | 主流说东我说西，但没新证据 | 立场不是观点 |
| 抽象感慨 | 无数字、无名字、无时间、无机理 | 无法验证，无法引用 |

## 五、人设资产（关注转化的复利）

读者关注你，是因为**可预期的判断方式**。三件事要长期稳定：

1. **稳定的判断框架**：让读者知道"遇到这类事，你会怎么看"。框架要能被复述（比如"永远先问谁在获利"）。
2. **明确的反对对象**：反对某种**偷懒的思考方式**，不是骂具体的人。
   > 例：「我反对的不是这家公司，是'用战术勤奋掩盖战略懒惰'这种自我感动。」
3. **敢认错**：判断错了必须公开复盘。**敢认错的判断者比从不犯错的和事佬更可信。**

---

## 六、判断台账与命中率（长期验证）

观点能力**唯一的硬验证是事后命中率**。每条公开发表的判断都必须记入 `~/WorkBuddy/公众号运营/judgments.md`：

```
日期 / 判断陈述 / 证伪条件（什么发生就算我错） / 检验日期 / 结果（命中·未中·未到期） / 复盘
```

- **季度统计命中率，目标 ≥60%**；低于 50% 说明判断框架需要修正（不是运气问题）。
- 命中的判断要**回捞**：写成"三个月前我说过 X，现在验证了"——这是建立权威最便宜的方式。
- 未中的要**公开复盘**，并说明当初漏掉了什么变量。

---

## 七、执行顺序（写每篇前必跑，不许跳步）

1. **列主流说法**：先写出别人会怎么评论这件事（≥3 条）——不知道主流是什么，就谈不上反共识。
2. **跑思维动作**：选 2-3 个动作，各产出一个候选观点。
3. **四问质检 + 反向测试**：筛掉假的，留下最硬的那个。
4. **共鸣映射**：明确这一篇触动读者的哪一条利益。
5. **前置观点**：**观点必须在开头 200 字内出现**，不能藏在结尾——大部分读者看不到结尾。
6. **记入判断台账**：写下判断陈述与证伪条件。

## 与其他规格的接口

- 本技能只负责**观点质量**；结构合规看主定义 §9 S 层，写作质量看 §9 C/T 层。
- 内容层 rubric 的「观点锐利度」维度，判定口径 = 本技能四问质检（可证伪 / 意外 / 解释力 / 利益关联）。
- 热点真实性由主定义 §8 四判据负责——**真实性未过的选题，不做观点加工**（不在一个假热点上展示判断力，那是双重损失）。
