# 设计说明 · 发布管线表单「封面预览 + 宽度重排」

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-26 |
| 需求来源 | 橙子哥哥原话：「表单那里要支持预览的呀」「表单的宽度，你重新设计下」 |
| 范围 | admin 前端 `ContentPipelineEdit.vue` + content-hub 新增只读接口 `GET /api/content/wechat-covers` |
| 关联 | Issue 5 封面配置（#449）已上线 `cover_media_id`；本篇在该基础上补「所见即所得」 |

## 1. 问题

线上表单两个痛点：

1. **封面配了看不到图**——`cover_media_id` 是文本框，贴一串 `BUSabtk9…` 根本无法确认选对了哪张图。运营只能靠猜。
2. **表单窄、字段平铺无层次**——`max-width: 960px`，比其他页面（1280px）窄；字段从上到下平铺，没有「编辑区 / 效果区」的节奏。

## 2. 方案

### 2.1 后端：封面素材列表接口（只读）

```
GET /api/content/wechat-covers?account=&offset=0&count=20
鉴权：用户 JWT（后台表单调用，走 class 级 JwtAuthGuard）
```

响应：

```json
{
  "items": [
    { "media_id": "BUSabtk9…", "name": "论文速报封面.png", "url": "https://mmbiz.qpic.cn/…", "update_time": 1793050000 }
  ]
}
```

- 实现：`WechatMpClient.listImageMaterials()` → 微信 `material/batchget_material`（type=image）
- `WechatMpPublisher.listCoverMaterials(account?)` 暴露给 controller（复用现有多账号 client 缓存）
- **url 是微信 CDN 地址**，前端直接用作缩略图/大图预览
- 只读接口，不改任何数据；失败时表单降级为纯文本输入，不阻断编辑

### 2.2 前端：表单重设计（1280 双栏 + 预览面板）

```
┌────────────────────────────────────────────────────────┐
│ ← 返回发布管线                                          │
│ 编辑管线：daily_paper                                   │
├───────────────────────────────────┬────────────────────┤
│ 表单区（flex:1）                  │ 预览区（360px）     │
│  编码 code │ 类型                │  sticky            │
│  cron     │ 标题模板             │ ┌───────────────┐  │
│  发布目标 │ 发布模式             │ │  封面大图      │  │
│  公众号封面 [缩略图选择器 ▼]     │ │ 2.35:1 预览    │  │
│  启用 ────────────────────      │ └───────────────┘  │
│  LLM prompt（通栏）               │  标题效果：        │
│                                   │ 「每日论文速览 ｜  │
│  [保存] [取消]                    │   2026-10-26」     │
│                                   │  发布摘要：        │
│                                   │  直接发布·公众号   │
│                                   │  封面：论文速报    │
└───────────────────────────────────┴────────────────────┘
```

要点：

| 项 | 做法 |
|---|---|
| 宽度 | `max-width: 960px` → `1280px`，对齐其他管理页 |
| 布局 | 双栏：左表单 + 右预览面板（sticky，随滚动跟随） |
| 封面选择 | 下拉选项带缩略图（选图即见图）+ 右侧大图预览；支持自定义 media_id 兜底（列表查不到时） |
| 标题预览 | live 渲染 `{{date}}` / `{{time}}` / `{{datetime}}`（对齐后端 `renderPlaceholders` 语义） |
| 发布摘要 | 模式 / 目标 / 启用状态 + 封面名，一屏可读 |
| 字段节奏 | 两列成对（code+类型 / cron+标题模板 / 目标+模式）、启用独立行、prompt 通栏 |
| 不动的 | `cover_media_id` 字段语义与后端传参不变；不引入素材库依赖（那是并行 WIP 的范围） |

### 2.3 兼容与降级

- 接口失败 / 无素材 → 封面下拉显示空态提示，仍可手输 media_id，保存不受影响
- 旧数据 `cover_media_id` 不在素材列表里 → 预览区显示「未在素材库找到，仍会按 media_id 使用」
- 不改 DB、不改发布链路、不写数据
