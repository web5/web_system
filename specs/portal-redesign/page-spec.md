## 2. 页面规格书 · 对话工作台（P1 主战场）

- 页面类型：详情页/工作台
- 参照页：小程序 `pages/chat/index/index`（主参照）+ 现有 `apps/portal/src/views/AiChat.vue`
- 需求一句话：把小程序单列对话流升级为 PC 三栏——左侧会话历史、中间消息流、右侧引用与来源，并接入统一的 agent/run 链路。

### 页头
- 标题：当前会话标题（无标题时显示首条用户消息截断，20 字）
- 副标题：仅显示作答 agent 徽标（如「合同翻译官」）；「自动识别」是默认行为，**不做文字标注**（2026-09-21 反馈）
- 主操作：**新对话**（primary，≤1）

### 模块清单（中栏，自上而下）

| 序 | 模块 | 数据来源/API | 承载组件 | 空态策略 | 备注 |
|---|------|-------------|---------|---------|------|
| 1 | 标题栏 | 会话实体 | 标题 + agent 徽标 + 「新对话」 | — | 隐藏全局页头，本页自带 |
| 2 | 消息流 | `POST /api/ai-agent/agent/run`（SSE） | 消息气泡列表，用户右对齐 / AI 左对齐 | 空态：欢迎语 + 3 个示例问题 chips | 用户消息可复制、失败可重试 |
| 3 | 输入区 | 同上 | 多行输入 + 发送 + 附件 | — | 支持 `⌘Enter` 发送 |

### 右栏
对话页**不设右栏**（2026-09-21 用户反馈：「引用与来源」无感知价值）。右栏仅在合翻报告（原文对照）与翻译（术语库）两处展示，其余页面不渲染、不留白。

### 交互清单

| 操作 | 触发 | 反馈 | 破坏性确认 | 完成后动作 |
|---|---|---|---|---|
| 发送消息 | `⌘Enter` / 发送按钮 | 消息立即上屏，AI 区显示思考动点 | — | 流式接收，完成后刷新会话列表标题 |
| 流式中断 | 生成中「停止」按钮 | 已生成部分保留，标注「已停止」 | — | 输入区恢复可用 |
| 失败重试 | 消息卡「重试」 | 重新发起该轮 | — | — |
| 复制 | 消息 hover 操作 | Toast「已复制」 | — | — |
| 新建对话 | 页头按钮 | 消息流清空 | 若当前有未发送消息 → 提示但**不阻断** | 左栏新增占位会话 |
| 删除会话 | 左栏 | 见外壳规格 | Modal.confirm | — |

### 状态覆盖自查
- [x] 加载中：SSE 等待 → 思考动点（非转圈 loading 覆盖全屏）
- [x] 空态：欢迎语 + 示例问题（有出路，非灰字）
- [x] 失败可重试：消息级重试按钮
- [x] 破坏性二次确认：删除会话
- [x] 禁用有 tooltip：生成中输入区禁用发送（防重复提交），附件按钮 tooltip「生成中暂不支持上传」
- [x] 保存中防重复提交：生成中发送按钮禁用
- [x] 无弹窗套弹窗：重试不弹确认

### 风险/待澄清
- Q4 已拍板：会话不隔离，左栏单一会话列表；`agentId=auto` 依赖意图路由开启（后端待办 B4），开启前 PC 端先显式指定 agentId 兜底。

## 3. 简版规格（P2–P4，落码前各自补 Full）

> P1 落码边界（2026-09-21）：§3.1 发现 / §3.2 翻译 / §3.3 合翻三页在 P1 只落**占位态路由**

### 3.1 发现（能力市场）· `/discover`
- 类型：列表页｜参照：小程序 `pages/discover/index/index`
- 模块：能力卡片网格（语言翻译官、合同翻译官（合翻） + 「敬请期待」占位卡）
- 交互：点击卡片 → 创建对应 agent 会话并跳入工作台
- 状态：加载骨架 / 空态「暂无可用能力」/ 失败重试
- 待澄清：**Q3 数据源**——`agent_definitions` 缺展示元数据列且无 C 端清单接口，未解决前卡片写死。

### 3.2 翻译工作台 · `/translate`
- 类型：表单/结果复合｜参照：小程序 `translate/{index,result,settings,history}`
- 布局：左=历史记录，中=源文本输入（语言对切换、语气/风格 chips、500 字计数），**右=对照栏（自然版/直译版/委婉版 Tab）**
- 增强：替代小程序折叠区为并排对照（§4.2）
- 状态：生成中（右栏骨架）/ 失败重试 / 空态「输入内容开始翻译」
- 交互：复制、朗读（`/api/ai/tts/speak`）、收藏、清空历史（二次确认）

### 3.3 合翻（合同翻译官） · `/contract`
- 类型：向导/报告复合｜参照：小程序 `contract/{index,upload,analyzing,assistant,result}`
- 步骤：选择方式 → 上传（拖拽 / 点击选择 / 粘贴，Q2）→ 分析进度（含「查看完整思考」抽屉）→ 报告
- 布局：中=报告（健康指数、风险信号、我的权益、权益最大化），**右=合同原文**
- 增强：报告 ↔ 原文联动，P3 先关键词回查兜底（Q1 已确认无定位字段；后端补 B3 后升级为精确定位）
- 状态：上传失败重试 / 分析中禁止离开（离开提示）/ 报告失败重试 / 空态
- 交互：导出报告、继续追问、批量导出（列表多选）
- 待澄清：**Q2 上传方式**

### 3.4 我的 · `/profile`
- 类型：详情页｜参照：小程序 `mine/{index,profile,settings}`｜内容区**撑满工作区宽度，不限宽**（2026-09-21 反馈；行列表、账号卡、会员卡均通栏）
- 模块：账号卡 → 应用设置（翻译 / 合同）→ 通用设置 → 我的数据（条数统计）→ 关于/退出
- 交互：头像与资料编辑、退出登录（二次确认）；会员卡占位「开发中」（Q5 已拍板）
- 待澄清：无

### 3.5 实验室 · `/lab`
- 类型：入口网格页｜承载：创作（秀秀（原变变，Q6 改名）/ 画板 / 相册）+ 效率工具（工具箱 / Todo）两组卡片；**左栏隐藏**（无记录语义，避免与卡片重复，2026-09-21 反馈），中栏撑满

- 待澄清：**Q6** 是否本轮下线

## 4. 跨页一致性约束

- 颜色/圆角/字号一律写 Token 名（`--ws-brand-500` 等），**规格中出现裸 hex 即打回**。
- 图标：内联 SVG 或 `@tabler/icons-vue`，禁 emoji。
- 间距：8 的倍数。
- 一屏 primary 按钮 ≤ 1。
- 所有异步流程必须有：加载中 / 空态 / 失败重试 三态。
