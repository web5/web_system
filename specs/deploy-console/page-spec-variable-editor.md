# 流水线变量行内编辑修复规格

## 范围

修复「编辑流水线 → 变量」及抽屉共用面板的既有交互，不新增页面、不改变路由或已确认的检索框、行内表单和表格布局，对应 `pipeline-edit-ui.md` 的变量 Tab。

## 行为

1. 点击行编辑后展开既有表单，滚动到可见范围并聚焦值输入框，支持页面和抽屉中的长列表。
2. 编辑态显示键名，普通变量回填完整原值；密钥值始终留空，不回填列表掩码。
3. 普通变量允许显式清空，密钥留空表示保留。已有密钥转普通变量必须填写新值，前后端均拒绝直接公开留存密钥。
4. 从编辑切换到新增或取消时清空原记录身份，不误用 update 修改上一条变量。
5. 保存期间防重复提交和切换编辑目标；失败保留输入。流水线切换后，旧请求完成不得重置或刷新新上下文。

## 验收

- 使用真实 Vue/Ant Design Vue 组件，在独立本机浏览器中验证页面与抽屉；API 隔离模拟，不读取真实凭据或接触发布闸门。
- 覆盖长列表定位/焦点、原值回填与清空、密钥保护、新增身份重置、失败重试、重复保存及切换流水线。
- 运行后端变量服务回归和前后端构建，不执行数据库迁移或生产变更。
- 合入、部署、真实页面复验前只标记本地修复验证完成，不把数据库代改当页面修复。

浏览器回归命令：`CONSOLE_BROWSER_RUNTIME=/path/to/runtime-with-puppeteer-core node scripts/verify-console-variable-editor.mjs`。支持 `CHROME_BIN` 指定本机 Chrome、`CONSOLE_VAR_EVIDENCE_DIR` 指定证据目录，不安装新依赖。
