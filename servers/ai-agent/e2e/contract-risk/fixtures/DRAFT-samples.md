## 审核前必读（两个影响判定语义的机制）

1. **关键词命中机制**：`contract-rule` 的 `matchByText` 是关键词 contains 匹配，只要合同文本里出现
   「利率 / 服务费 / 违约金 / 期数」等词就会命中对应尺子（无论实际风险高低）。因此：
   - 风险样本的 `expectSignalIds` 是「**必须出现**」的下集断言（agent 额外多报不判错）；
   - 「干净样本」用**级别断言**而不是「零命中」断言（见 S6 说明）。
2. **scene 过滤风险**：若 agent 调 `contract-rule` 时传 `scene=car-loan`，尺子池 = `car-loan + other`，
   而目前**购车贷/融资租赁没有专属尺子**、贷款尺子全在 `consumer-loan` 下 → 会漏报。
   工具描述已写「留空自动扫描全部」，**样本的隐式期望 = agent 应走全量扫描**（S2/S3 顺带验证这点）。

## S1 · consumer-loan-01 消费贷款（高息 + 砍头息 + 强制搭售）

### 合同全文

```

合同编号：XF2026-0918-1101

甲方（贷款人）：XX消费金融股份有限公司
乙方（借款人）：【借款人姓名】，身份证号：【身份证号】

第一条 借款金额与期限
1.1 甲方向乙方提供个人消费贷款人民币（大写）壹拾万元整（¥100,000.00）。
1.2 贷款期限为 12 个月，自放款日起算。

第二条 费用与放款
2.1 乙方同意向甲方支付一次性贷款咨询服务费人民币 5,000.00 元（含税费）。
2.2 上述服务费由甲方在放款时直接从贷款本金中预先扣除，乙方实际到账金额为人民币 95,000.00 元。
2.3 甲方放款后向乙方出具电子借据一份。

第三条 还款方式
3.1 本贷款采用等额本息还款方式，乙方应于每月 10 日前偿还贷款本息人民币 9,500.00 元，
     共 12 期，每期还款包含当期利息及本金分摊。
3.2 乙方可通过甲方 APP、微信、支付宝等渠道还款。逾期未还的，甲方有权按日收取逾期利息。

第四条 增值服务
4.1 为提升乙方借款体验，本产品默认开通「尊享会员服务」，服务费 899 元/年。
4.2 尊享会员包含优先审批、专属客服、额度评估报告三项权益。乙方可在借款到账后联系客服申请退订，
     退订后不影响本合同其他条款效力。

第五条 提前结清
5.1 乙方可随时申请提前结清全部贷款。提前结清的，甲方按剩余本金的一定比例收取费用，具体以结清时
     甲方系统显示为准。

第六条 违约责任
6.1 乙方逾期还款的，自逾期之日起按未还本金的日万分之五计收违约金。

甲方：XX消费金融股份有限公司（盖章）
乙方：【借款人姓名】（签字）
日期：2026 年 9 月 18 日
```

- [ ] 2.2「预先扣除」命中 `kickback-interest`；月供 9500 推得 IRR 41.3% → 命中 `usury-interest`（danger 实锤）
