# 语音输入 icon 设计规范与最佳实践

> 定稿：**声波 L1 立弧**（v1.0.13，2026-10-12）· 状态：**现行**
> 适用范围：科豆 AI 小程序对话页输入栏录音键；PC 端复用见 §5 通用资产。
> 本文是最佳实践的正式落文档；方法论同时沉淀于 skill `icon-design-pipeline`（专项）与 `visual-design-workflow`（总纲）。

---

## 1. 定稿形态

实心圆点 + 右侧双层同心弧（微信语音输入同款构图），整组光学居中——**圆点偏左是构图的一部分，不是居中对象**。常态线性（浅橙底 + 橙图标），录音中面性（实心橙底 + 白图标）。

| 态 | 色值 | 场景 |
|---|---|---|
| 常态 | #F97316 | 录音键 idle |
| 录音中 | #FFFFFF | `.is-rec` 实心橙底反白 |
| 单色墨 | #1F1F1F | 暗色 / 备用 |

## 2. L1 几何参数（24 网格，SVG 唯一真源）

| 项 | 值 |
|---|---|
| 圆点 | cx 6.90 · cy 12 · r 2.5（实心） |
| 内弧 | r 7.25 · `M11.75 6.61 A7.25 7.25 0 0 1 11.75 17.39` |
| 外弧 | r 11.55 · `M14.63 3.42 A11.55 11.55 0 0 1 14.63 20.58` |
| 张角 | ±48°（端点与水平轴夹角 = 立弧） |
| 线宽 | sw 2.3，全圆头 |
| 光学居中 | `dot_cx = 12 − (r2 − dot_r)/2 − sw/4`（含线宽补偿） |

**半弧铁律**：端点 `(cx + R·cosθ, cy ± R·sinθ)`，上下端同 x、关于水平中线严格镜像。端点一偏左一偏右，整条弧就是斜的——J/K 两代「歪」的真凶。

## 3. 27px 真机验收数据

宽 64% × 高 81% · 点弧细缝 1.35px（吻而不糊）· 弧间距 2.25px（清晰分层）· bbox 中心 = 画布中心。

## 4. 设计规范（icon 专项，11 条）

| # | 规范 | 一句话 |
|---|---|---|
| A1 | SVG 唯一真源 | 原型 inline、真机位图、base64 必须同源派生；两套几何代码必漂移 |
| A2 | 半弧端点同 x 镜像 | 端点一偏左一偏右，整条弧就是斜的 |
| A3 | 光学居中含量宽补偿 | 左极（圆点无描边）与右极（外弧外撑 sw/2）取中，多退 sw/4 |
| B1 | 按最终显示尺寸设计 | 27px 真机下 1 格=1.1px，缝隙按 px 反推（点弧 ≥1.2px、双弧 ≥2px） |
| B2 | 选型稿只用 1:1 与 ≤2x | 禁放大镜骗眼；迭代稿带「旧病形态」灰色对照块 |
| B3 | 落码前像素级自检 | 缩到显示尺寸 NEAREST 放大，端点/缝隙/粘连出对照图留档 |
| C1 | 每代只验一个变量 | 症状不消失就回代码找构造级 bug，禁凭感觉调参 |
| C2 | 用户拍板才落码 | 「落码 Lx」式确认 + spec 记迭代链 |
| C3 | 歧义短语先确认语义 | 「弯曲了点」=放平弧还是加大张角？先问再画 |
| D1 | 资产包四件套 | 三态 SVG + 多尺寸 PNG + base64 + README 参数表 |
| D2 | 换挡公式 | span 调弯曲感、r2/dot_r 同步调饱满度、居中公式不变 |

## 6. 通用设计工作流（摘要，全貌见 skill `visual-design-workflow`）

```
Expert 定标准 → 截图多模态定位病因 → 参数化 SVG 生产 → 真机 1:1 拍板
→ 落码 + PIL 像素自检 + 预览码上真机 → 资产包/spec/skill 即时沉淀
```

五层能力栈：Expert 层（工艺标准前置）· 感知层（截图直传 + 多模态读图）· 生产层（SVG 真源 + 无头 Chrome 光栅化 + 选型稿渲染）· 验收层（miniprogram-ci 预览码 + git 分支隔离）· 沉淀层（skill + 资产包 + 归档 + 记忆）。
