# 交互规格 · 对话页「语音输入」（按住说话）

> 原型/规格文件（门禁通行证）。对应落码：
> `apps/kedou-ai-minigram/services/asr.ts`、`pages/chat/index/index.{ts,wxml,wxss}`。
> 2026-10-11 修订（长按语义回归修复）。

## 1. 一句话定义

输入栏麦克风 = **按住说话**：手指按下开麦，抬起即结束并识别；上滑取消。
识别结果**回填输入框**（可编辑）而非直接发送。

## 2. 状态机（唯一真相源）

| 态 | 含义 | 触发 | 浮层文案 | 波形 |
|---|---|---|---|---|
| `idle` | 未录音 | 初始 / 收尾 | 不显示浮层 | — |
| `preparing` | 手指已按下，正在走隐私协议 + 录音授权（**尚未开麦**） | touchstart | 准备中… | 静止（busy） |
| `recording` | 已开麦，计时中 | 授权通过 | 松手识别，上滑取消 / 松开手指取消 | 动 |
| `recognizing` | 已松手，等云端结果 | touchend | 识别中… | 静止（busy） |

不变量（写测试锁死，见 `tests/asr-hold.test.ts`）：

1. **按下即同步入 `preparing`** —— 不能等授权 `await` 完才置态，否则手指已抬起也感知不到。
2. **`preparing` 期间松手 / 被系统打断（touchcancel、页面卸载）→ 不开麦、状态归位**。
3. 手指离开 = 本次结束；不存在"松手后才开麦、无人收尾"的路径。

## 3. 为什么必须有 `preparing` 态（事故原型）

隐私协议 + 录音授权是**异步**的，首次按下还会弹系统授权框（1s 量级）。
旧实现在 `await` 期间状态仍是 `idle`：

- touchend 判定「不在 recording」→ 直接 return，不调 stop；
- 授权回来后录音才真正启动 → 没人再给它结束信号；
- 表现：**点一下麦克风也会弹出录音浮层且停不下来**（直到 60s 上限），长按语义被架空。

同一事故的次因：授权结果**不缓存** → 每次按下都要再 `await` 一次，用户感知"按了没反应"。

## 4. 手势与判定

| 手势 | 判定 | 结果 |
|---|---|---|
| 按下 | `touchstart` | 入 `preparing`，开麦前 `stopSpeak()`（防回声自激） |
| 上滑 > 60px | `touchmove` | 置"取消"态，浮层文案「松开手指取消」 |
| 抬起（取消态） | `touchend` | 丢弃本次录音，不动输入框 |
| 抬起（正常） | `touchend` | 结束录音 → 识别 → 回填输入框 |
| 系统打断 | `touchcancel` | 同"取消"；`preparing` 态同样要取消 |
| 到 60s 上限 | 计时器 | 自动结束并识别（一句话识别上限） |
| 录音 < 500ms | onStop 判定 | 视为误触，提示「按住麦克风说话，松手识别」 |

## 5. 失败/边界态

| 情况 | 表现 |
|---|---|
| 未登录 | toast「请先登录」，不进 preparing |
| 隐私协议未同意 | 引导授权；拒绝则 toast「需要同意隐私协议才能使用语音」 |
| 录音权限被拒 | modal 引导去设置开启（`scope.record === false` 时） |
| 503（云上未开通/未配置） | toast「语音识别服务未开通」——运维问题，不引导用户重试 |
| 网络/其它失败 | toast 具体 message 或「识别失败，请重试」，不回填 |
| 识别空文本 | toast「没听清，请再说一次」 |

## 6. 与朗读（TTS）的关系

- 开麦前必须 `stopSpeak()`：否则麦克风收进扬声器声音，识别结果全是胡话。
- 自动朗读开关（落 storage）与录音互斥于同一时刻：录音时必然已停播。

## 7. 视觉规格

沿用输入栏既有控件语言：`.chat-mic` 与 `.chat-plus` / `.chat-send` 同规格（尺寸、圆角、
`--brand` 主色），录音中加 `.is-rec`；浮层 `.voice-mask` 用 `--card` + 半透明遮罩。
未引入新视觉体系 —— 本次仅新增 `preparing` 态文案与波形静止态。

## 8. 修订记录

### 2026-10-11 23:45 · 真机反馈修订（v1.0.6）

真机验证发现三点，均按本节修订后落码：

1. **麦克风 icon 不像**：旧实现只有「竖条 + 底横线」两笔，识别度差。
   改为标准三笔造型：胶囊话筒头 + U 形拾音支架 + 底部短杆（`.chat-mic::before/::after`
   + 新增 `.mic-stem`），纯 CSS 不引图标字体。
2. **布局**：麦克风与「+」同列左侧（`+ 麦克风 自动朗读 | 输入框 | 发送`），
   右侧只留发送键 —— 左手拇指易达，输入框获得最大宽度。
3. **「录音结束后弹窗不消失」兜底（防 touchend 丢失）**：
   - 浮层遮罩补绑 `bindtouchend / bindtouchcancel / bindtouchmove` —— 部分真机会把
     触摸序列派发给 hit-test 到的全屏遮罩而非原按钮，绑上即能收尾；
   - `releaseAsr()` 加 4s 看门狗：`recorder.stop()` 后 `onStop` 迟迟不回（真机偶发）
     则强制 `finish(null)` + toast，浮层必消失。

不变量补充第 4 条：**任何路径下浮层都必须能回到 idle** —— 松手、打断、60s 上限、
onStop 丢失、识别失败，全部有收尾出口，不允许悬挂态。

### 2026-10-11 23:59 · 麦克风 icon 修订 v2（v1.0.7）

v1.0.6 的伪元素三笔造型真机复验仍「不像」：WXSS 只有 `::before/::after` 两个伪元素
+ 一个实体子节点，22px 显示尺寸下笔画比例失真、rpx 取整出锯齿，拼不出标准麦克风。

修订：**放弃 CSS 拼笔画，改用 @3x 位图内联**。

- 生成：`scripts/gen-mic-icon.py`（Pillow，4x 超采样 + LANCZOS 降采样，几何参数见脚本头部），
  造型 = 实心胶囊话筒头 + U 形拾音支架 + 颈杆 + 底座横线（Material mic 同构）。
- 内联：小程序 WXSS 的 `background-image` **不支持本地相对路径，只吃 base64 / 网络图**，
  故以 data URI 写进 `.chat-mic` / `.chat-mic.is-rec`（橙 `#F97316` / 白 `#FFFFFF` 两配色，
  对应常态浅橙底与录音中实心橙底），`background-size: 44rpx`。
- 体积：两张 PNG 共 ~4.9KB（base64 后 ~6.5KB），对包体（309KB）可忽略。
- 复现：改几何参数后跑 `python3 scripts/gen-mic-icon.py`，把输出的两段 base64
  替换进 `index.wxss` 即可。

顺带：出码脚本 `scripts/preview.js` 增加**过期时间产物**（预览码官方口径 25 分钟，
体验版 7 天）—— `preview-qr.html` 卡片带「有效期至 + 剩余倒计时」，`preview-qr.meta.json`
机器可读，PNG 另存带生成时刻的副本，后台 desc 同步写有效期。

### 2026-10-12 00:20 · 输入栏 icon 质感选型定稿（v1.0.8）

用户反馈：① 输入栏的「自动朗读」常驻开关 icon 不需要；② ➕ / 🎙 质感不行，先出选型稿再实现。

**选型稿四方案**（线性 / 面性 / 双色调 / 厚涂 clay）过目后拍板：

1. **常态 = 线性 line**：浅橙底 + 橙细描边（Tabler 式麦克风：瘦长胶囊 + U 形拾音架
   + 杆 + 底座；加号细描边十字）。➕ 与 🎙 统一同语言。
2. **录音中（高亮）= 面性 filled**：实心橙底 + 白面性麦克风 —— 激活态有明确视觉跃迁
   （用户补充：高亮时用面性）。
3. **去掉输入栏「自动朗读」开关**：`chat-auto` 节点/样式、`onToggleAutoSpeak`、
   `autoSpeak` data 与 storage、回复完成后的自动播报调用全部摘除（入口没了，
   留着是死代码）；朗读能力保留 —— AI 回复气泡上的「朗读/停止」按钮照旧。

工程口径：线性 / 面性两套均为 Pillow 位图（`scripts/gen-mic-icon.py`，几何见
`mic_line()` / `mic_fill()`）内联 WXSS。线性麦克风弧线是踩坑重点 —— 弧端点低于
胶囊底会成「Y」形分叉，高于胶囊底会成「耳朵」；定稿：**端点与胶囊底同高、弧明显
外张**（Tabler mic 比例，弧端点 x=±96、胶囊 ±48、底 y=190）。

**同步至主稿**：本节定稿已集成进统一原型稿 `prototype/index.html` 的对话页输入栏
（➕ / 🎙 线性 SVG + 录音中面性 + 录音浮层四态演示，可交互），配套截图
`prototype/预览-输入栏-语音输入.png` / `预览-输入栏-录音中.png`。
