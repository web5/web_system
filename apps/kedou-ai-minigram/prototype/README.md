# kedou-ai-minigram · 原型稿清单（总索引）

> 用途：一份表说清小程序有哪些功能页面原型稿、各自状态、与规格书 / 实施清单的对应关系。
> 改码前先过原型（动作门第 3 步：原型经确认后才落地代码）。

## 1 总入口

```bash
open apps/kedou-ai-minigram/prototype/打开原型.command   # 起本地服务并打开总入口
# 或：在 prototype/ 下直接双击 hub.html
```

- 入口页：**`hub.html`** —— 左侧切换各稿，右侧 iframe 承载本体；支持 `#文件名.html` 直达（如 `hub.html#music-taste.html`）。
- `打开原型.command`：端口 `8722`，服务根为小程序目录上一级（`--directory ..`），因此 `prototype/` 与 `docs/` 下的稿都能访问。

## 3 主交互稿页面地图

### 3.1 `index.html`（14 屏）

```
欢迎页（覆盖层，非 Tab）
├─ 开始对话 → switchTab 对话
Tab 对话（隐藏 tabBar，沉浸式）
├─ 对话记录（二级）
├─ 失败态：这一轮发送失败 / 回复流式中断（气泡级，非整页）
└─ 意图徽标（哪个 agent 作答）
Tab 发现
├─ 语言翻译官 → 翻译输入 → 翻译结果 / 翻译失败态
│                └─ 翻译历史 · 翻译设置
└─ 合同评估 → 上传页 → 评估结果
              └─ 评估设置
Tab 我的
├─ 个人信息
└─ 小程序设置（应用设置 / 通用）
```

### 3.2 `music-taste.html`（3 模块 + 1 占位）

```
Tab 对话 · 音乐卡片（换一批 / 不感兴趣 / 去 QQ音乐听）
Tab 发现（本次范围外，仅占位保证可达）
Tab 我的 · AI 记忆 → 音乐口味
音乐口味页（二级）：扁平标签列表 · 增删 / 补充 / 清空 / 空态
```
