## D1 变体（设计输入评审）

差异：对象为需求 spec / 方案；不查视觉条目（E/F/G），重点查 **A / B / M**（信息架构、任务模型、未定义项）与 **P1–P6** 原则；产出结论只作输入，不产生阻塞计数时写 `阻塞: 0`。

## D3 变体（实现一致性评审）

差异：对象为已实现代码 + 截图；必查 **N 维度**（锚点 / 可机检条目 / 截图并置差异）。

- 锚点缺失或改名 → 阻塞，判据 `[X9]`
- 存量页面尚未回填锚点 → **不判为漂移**，在报告标注「锚点未回填，本轮跳过比对」（依方案 §3.7.1）
- 截图存 `docs/ui/baselines/{app}-{page}-{proto|impl}.png`，差异按 E/F/G/H/I 逐维度列出
