# 版本化产物链

所有中间结论必须落盘为文件，而非仅存在于对话中：
- 方案结论 → `intent.md`
- 大纲结构 → `spec.md`
- 成稿 → 保留修订版本，不以后一版覆盖全部历史

落盘产物的价值：可追溯每一步决策、可回溯任意版本、可交接协作。

## 判定手段

- 存在性：`scripts/check-artifacts.sh <工作区目录> [任务ID]`，输出落盘率（D1 机器可判定部分）。
- 入库检查：产物文件未被 `.gitignore` 忽略——`git check-ignore -v <产物路径>` 返回 0 即视为未落盘。
- 版本化：成稿保留修订版本，不得以后一版覆盖全部历史（L4 任务卡 D1 抽查）。

## 不适用

- 纯过程性结论已在 spec / 判据表中被引用（此时不强制另建文件）。

> 为什么「只在对话里」不算落盘：见 [`RATIONALE.md`](RATIONALE.md) §3。
