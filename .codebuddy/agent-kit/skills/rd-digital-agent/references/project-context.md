## 通用原则（适用于任何项目）

- 同类修改必须扫全量，不只在手头文件改。
- 横切关注点（校验 / 日志 / 配置）统一收口，禁止各端拷贝。
- 对外交付物变更需同步更新 spec 与版本记录。
