# 机构行为全周期追踪框架 V2.3 — 完整文档

**版本**：V2.3
**更新日期**：2026-08-13
**适用周期**：中线持股（1-6个月）
**核心升级**：在V2.1基础上，新增**反向雷达（回调强势票）双通道选股**——正向四维验证抓"机构拉升初段"，反向雷达抓"基本面强+机构温和加仓+股价回调"的潜力票，修复"海光信息类标的被漏筛"的结构性盲区。
**输出升级（V2.3）**：报告统一采用**决策面板三档**格式（档1值得跟/档2观察/档3回避），每只票只给结论+动作+触发价，模板与实盘示例见第七章。

## 一、核心逻辑（四维验证法 + 离场机制）

投资的完整周期是：**选股 → 持股 → 离场**。

> **第一步（选股）**：四维法找"机构在建仓/拉升初期"的票。
> **第二步（持股）**：动态监控"机构参与度"是否持续为正。
> **第三步（离场）**：一旦触发离场条件，机械执行减仓/清仓。

**四大维度定义**：
- **维度一：静态仓位** —— 看机构拿多少（解决"能不能买"的方向问题）
- **维度二：动态行为** —— 看机构正在做什么（解决"什么时候买/卖"的时机问题）
- **维度三：成本与估值** —— 看机构是否比你便宜（解决"值不值得赌"的盈亏比问题）
- **维度四：北向资金** —— 看外资在买还是在卖（增量确认，条件启用）

> **维度四启用条件**：该股须为**沪深港通标的**且有北向持仓数据。小盘股、次新股无北向数据时，退化为三维验证。

## 二、详细操作标准（选股篇）

### 第一步：静态仓位筛查（找"底仓"）
> **数据源**：最新季报/半年报的"前十大流通股东"及"公募基金持股比例"。

- **剔除线**：机构持股 < 3%（无话语权，易暴涨暴跌）。
- **观察线**：机构持股 3% - 15%（轻度配置，需结合动态数据）。
- **重点池**：机构持股 > 15%（机构压舱石，逻辑受认可）。
- **加分项**：前十大流通股东中出现 **社保基金**、**大基金** 或 **顶级外资（如阿布扎比、新加坡政府投资）** 且为新进。

### 第二步：动态行为监测（抓"时机"）—— 核心避坑环节
> **数据源**：Level-2数据（东方财富/同花顺）、龙虎榜、公告调研记录。

1. **机构参与度**（实时主力资金流向）：
   - 数值为正（+）且较大：机构近期主动买入，信号积极。
   - **数值为负（-）**：**即使季报持仓高，也须暂缓介入**，说明机构正在偷偷卖出。
2. **龙虎榜席位**：
   - 买入信号：出现"机构专用"席位且 **净买入 > 5000万**，真金白银抢筹。
   - **危险信号**：出现机构席位 **净卖出**，无论逻辑多好，短期回避。
3. **机构调研频次**：
   - 近1个月内密集接待 **超100家** 机构调研：公司可能出现潜在变化，机构正在做买入前的功课。

### 第三步：成本与估值锚定（定"盈亏比"）
> **估算机构成本**：取龙虎榜机构买入均价，或近期放量平台的中枢价格（筹码峰单峰密集区）。

**计算"股价偏离度"**：
> 偏离度 = （当前股价 - 机构成本） / 机构成本 × 100%

| 偏离度范围 | 安全评级 | 操作建议 |
| :--- | :--- | :--- |
| **< 15%** | **高安全边际** | 机构尚未大幅获利，最佳黄金跟踪区。 |
| **15% - 50%** | **合理区间** | 趋势确认中，若动态数据持续向好可介入。 |
| **> 80%** | **高风险区** | 机构获利丰厚，随时可能兑现，严禁追高。 |

### 第四步：北向资金（外资）—— 增量确认维度 ⭐ V2.1 新增
> **数据源**：沪深港通每日北向资金流向、个股北向持股比例及持仓变动（东方财富/同花顺均有）。

1. **北向持股比例**（静态仓位）：
   - < 1%：低关注，外资影响力有限。
   - 1% - 5%：中等配置，作为辅助参考。
   - **> 5%**：重仓关注，外资定价权显著。
2. **北向净买卖**（动态行为）：
   - **连续 5 日净买入**：外资持续加仓，与机构正流入形成双确认。
   - **连续 3 日净卖出**：外资撤离信号，即使内资机构仍看好，也须提高警惕。
3. **内外资分歧判定**：
   - 内资机构正流入 + 北向净卖出 = **分歧**，下调评级，暂缓介入。
   - 内资机构正流入 + 北向净买入 = **共振**，最强买入信号。

### 第五步（补充通道）：反向雷达 —— 回调强势票扫描 ⭐ V2.2 新增

> **背景**：V2.0-V2.1 的筛选漏斗天然偏好"机构重仓（>15%）、主力资金流入、股价在涨"三类信号，擅长抓**已启动的机构票**，但会漏掉下面这一型：
> **"基本面很强、机构在悄悄加仓、股价却正在回调、估值偏贵"的潜力票**。
> 典型案例：海光信息（688041）—— 中报营收+66.5%/净利+49.7%、基金持仓8.65%→9.17%，但股价距高点回撤28%、PE-TTM 280，旧流程三道关卡全被过滤。
> **每次选股，除主通道四维验证外，必须并行执行本轮反向雷达扫描。**

**条件组B（全部满足才入池）**：

| 条件 | 标准 | 说明 |
| :--- | :--- | :--- |
| 成长性 | 营收/净利同比增速 > **40%** | 比主通道20%更严，确保真成长 |
| 机构态度 | 持仓 **3%-15%** 且**环比加仓** | 基金持仓环比上升 / 机构家数增加 |
| 股价位置 | 距60日高点回撤 > **20%** | 正处于回调而非拉升初期 |
| 当日资金 | 净流入/流出均可 | 回调期流出属正常，**不作为剔除依据** |

**估值处理规则（与主通道不同）**：
- PE > 100 的高估值票 **不自动剔除**，单独标记"高估值"，**转人工评估**。
- 评估框架：看 PEG（PE ÷ 增速）。PEG < 2 或增速足以覆盖估值 → 保留观察资格；PEG > 3 且无业绩加速逻辑 → 剔除。

**评级归属与升级信号**：
- 通过通道B入池 → 默认 **观察级（回调蓄力）**，不直接买入。
- 出现任一信号即升级评估：
  1. 回调**缩量企稳**（支撑位不破 + 量能萎缩）；
  2. **放量突破**回调平台/前高压力位；
  3. 下季度机构数据**确认继续加仓**。

## 三、综合评级与建仓决策（买入篇）

| 四维验证结果 | 综合评级 | 具体行动指令 |
| :--- | :--- | :--- |
| **高持仓 + 参与度正流入 + 股价偏离度 < 20% + 北向重仓/净买入** | **S级（黄金坑）** | 重点建仓，或在大盘回调时加仓。 |
| **高持仓 + 参与度正流入 + 股价偏离度 20%-50%** | **A级（趋势中）** | 已有持仓坚定持有，轻仓者分批低吸。 |
| **高持仓 + 参与度负流出 / 龙虎榜净卖出 / 北向持续流出** | **C级（危险）** | **坚决回避**。已有持仓者应趁反弹减仓离场。 |
| **低持仓 + 调研暴增（>100家）** | **观察级（预期差）** | 放入自选股重点观察，等待下季度季报确认增仓。 |
| **强增速(>40%) + 机构温和加仓 + 股价回调>20%（通道B入池）** | **观察级（回调蓄力）** | 不直接买入，等企稳/突破/季报确认信号再升级评估 |

> **评级修正规则**：北向资金连续净卖出时，即使前三维达标，评级**整体下调一档**（S→A，A→观察）。

## 四、持仓监控与离场机制（卖出篇）

> **核心原则**：机构出货极少是一根大阴线砸完的，而是**高位反复震荡、制造"还能涨"假象**的过程。四维法在此时的任务是：**识别"动态数据转负"的拐点**。

### 1. 四大高危时间窗口（到点必须提高警惕）

| 时间节点 | 危险逻辑 | 操作指引 |
| :--- | :--- | :--- |
| **4月底（年报/一季报）** | 市场提前1-2月炒预期，财报发布时"卖事实"兑现 | 财报前若已大涨，财报公布当日参与度骤降则清仓 |
| **8月底（中报）** | 同上，且叠加年中资金结算压力 | 同上 |
| **10月底（三季报）** | 机构全年业绩基本定型，开始锁定利润 | 11月前主动减仓，规避年末调仓踩踏 |
| **12月中旬-1月初** | 银行回笼资金、公募保排名、私募应对赎回，流动性枯竭 | 此阶段尽量空仓或轻仓，不轻易抄底 |

### 2. 三大致命盘面信号（看到任何一个就高度警惕）

- **信号一：高位放量滞涨**。股价已涨超50%，成交量异常放大（达前期均量2-3倍），但股价连续3天不创新高。这是典型的"对倒出货"。
- **信号二：低位筹码向上转移**。通过筹码分布图查看——**底部的单峰密集区明显缩小，高位出现新的峰堆**，说明机构正在把低位筹码派发给追高者。
- **信号三：大单托底却不涨**。盘口买一到买五挂出巨额买单，但卖单源源不断砸出，股价纹丝不动。这是机构用大单制造"有支撑"的假象，吸引跟风盘。

### 3. 四维法卖出条件（系统化离场决策矩阵）

当以下条件**同时满足2项及以上**时，触发减仓/清仓指令：

| 条件编号 | 具体信号 | 数据来源 |
| :--- | :--- | :--- |
| **⚠️ 条件A** | **机构参与度**由正转负，且连续3日净流出 | Level-2数据 |
| **⚠️ 条件B** | 龙虎榜出现"机构专用"席位**净卖出**（单日>3000万） | 龙虎榜 |
| **⚠️ 条件C** | 当前股价偏离机构成本 > **80%**（获利盘极重） | 筹码峰/龙虎榜均价 |
| **⚠️ 条件D** | 所处行业处于**上述4个高危时间窗口**内 | 日历 |
| **⚠️ 条件E** | **北向资金**连续3日净卖出（外资撤离） | 北向资金数据 |

**决策指令**：
- 触发1项：**暂停买入，开始分批减仓**（卖1/3）。
- 触发2项及以上：**坚决清仓离场**，不参与鱼尾行情，不被"可能还有第二波"的幻想绑架。

### 4. 散户反向指标（离场确认加分项）⭐ V2.1 新增

> 散户信号**不独立触发离场**，而是在其他离场条件已触发时，作为**增强确认**，使决策更坚决、更快速：

| 散户信号 | 含义 | 作用 |
| :--- | :--- | :--- |
| 龙虎榜**散户席位净买入激增** | 追高资金大量接盘 | 确认"机构在派发" |
| 筹码**高位集中到散户** | 高位筹码峰对应散户持仓 | 派发完成的直接证据 |
| 融资余额高位陡增 | 杠杆资金狂热 | 情绪见顶的辅助信号 |

> 出现任一散户反向信号 + 任一主离场条件（A-E）时，视为**"双重确认"**，应直接清仓而非只减1/3。

## 六、报告输出：决策面板三档模板 ⭐ V2.3 新增

> 原则：**信息服务于决策**。任何分析/扫描报告按面板三档输出，每只票只保留"结论+动作+触发价"，数据细节作为面板依据附注，不以大表格为主呈现。

### 1. 面板结构

| 区块 | 内容要求 |
| :--- | :--- |
| 一句话结论 | 扫描类：先给定性结论（扫N只→只有X只值得看）；个股类：给当前评级判定 |
| 档1 值得跟 | 有明确动作，必带【触发条件】+【失效价】 |
| 档2 观察等待 | 写明"等什么"（等回踩/等企稳/等季报确认/等放量突破）|
| 档3 回避 | 写明"为什么"（机构减仓/估值过高/主力流出），一句话 |
| 做什么/不做什么 | 未来1个周期（周/月）的两条行动纪律 |

### 2. 单票字段规则

- **名称+代码**：必填。
- **一句话依据**：≤15字，只写决定性的一条（如"基金8.65→9.17%加仓""距60日高点-27.6%"）。
- **动作**：动词短语（等放量站上300 / 可分批建底仓 / 别碰）。
- **触发/失效**：档1必给触发价与失效价；档2给观察条件；档3写原因即可。

### 3. 模板示例（2026-08-13 双通道全市场扫描）

**一句话结论**：全市场1125只高增速股排雷后，**只有1只完整命中**（机构在加仓 + 深度回调），其余要么机构在减仓，要么回撤没够。

| 档位 | 标的 | 一句话依据 | 动作 |
| :--- | :--- | :--- | :--- |
| 档1 | 海光信息 688041 | 基金8.65→9.17%加仓，回撤-27.6% | **不追**，等放量站上300；跌破255放弃 |
| 档2 | 宁德时代 | 机构59%重仓 + 低估值 | 可分批建底仓 |
| 档2 | 紫光股份/浪潮信息 | 主力+16.4亿/+11.1亿，机构仓轻 | 等回踩再低吸 |
| 档2 | 药明康德 | 机构加仓，但已涨58% | 已涨多，等回调 |
| 档3 | 中际旭创 | 机构Q2减仓29% + PE126 | 别碰 |
| 档3 | 紫金/洛钼/山金/华友/五粮液 | 机构Q2集体减仓 + 回撤<20% | 机构在撤 |

**做什么 / 不做什么**：
- 做：盯海光 8/14-8/20 中报兑现反应，放量上300 再动，跌破255 放弃。
- 不做：不左侧抄底、不碰档3、不追已涨多的票。

## 七、该框架的风险边界（纪律）

本框架解决的是**"资金面和情绪面"**问题，无法应对**"基本面突变"**（如行业打压、技术颠覆、业绩暴雷）。

**在使用此框架筛选前，请务必执行"5分钟排雷"**：
1. **业绩排雷**：最新季度营收和净利润同比增速是否 > 20%？
2. **估值排雷**：当前市盈率（PE）是否处于行业历史中位数的合理区间？
3. **消息面**：近1个月是否有重大利空媒体文章？

**若基本面严重不达标（如业绩下滑），机构随时会因"逻辑证伪"而集体抢跑，此时四维验证完全失效。**

**维度四适用范围**：北向资金数据仅覆盖沪深港通标的，小盘股、次新股无北向数据，应退化为三维验证。
