概述

科豆 AI 平台采用「暖橙」品牌色系，基于 Ant Design Vue 4.x + CSS Variables 实现多主题方案。Portal 端为暖色亮色主题，面向 C 端用户；Admin 后台支持亮色/暗色双主题切换（默认亮色），面向管理运营。
