## 建议（无判据硬伤，个人偏好，可驳回）

1. **字号阶**：`.g-en` 用 15px、`.g-src` 用 13px，未严格落在品牌端字阶（E4）。但品牌端原型存量即存在 12.5px/11.5px 等非整档，且英文主文 15px 为突出译文有意放大——建议落码时归拢到端字阶，非阻塞。
2. **间距阶梯**：`.mem-item`/`.tagbox` 用 14px、`.gloss-item` 用 10px 等非 8 倍数（F1）。与现有 `.list .r` 的 14px 基线一致，属「就近归拢」范畴，落码时按 `app.wxss` 阶梯（8rpx 基准）微调即可。

> 两处建议均不影响本稿作为交互设计交付的合格性，交由人审裁决。
