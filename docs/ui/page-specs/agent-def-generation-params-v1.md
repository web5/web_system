## 2. 涉及 Token（禁裸值）

`--ws-brand-500/600`（主操作）、`--ws-bg-active`（**分段控件选中态**）、`--ws-bg-subtle`（禁用控件底 / chip / note 底）、
`--ws-text-primary/secondary/tertiary/disabled`（层级）、`--ws-border`、`--ws-radius-md/sm`、`--ws-control-sm/md`、`--ws-danger`（校验错误）。
另需 `--ws-overlay`（遮罩）与 `--ws-shadow-float`（浮层阴影）：**两者在 `tokens.ts` 尚未定义，先入包再引用**（原型侧临时定义，已注明待删）。

**不用** `--ws-brand-500` 做分段控件选中态：白字压 #F97316 仅 2.8:1，不过 AA；改用 `--ws-bg-active` + `--ws-text-primary`（约 15:1）。
不发新色；不新增 `!important`。

### 2.1 字阶与间距（评审回流：阶外值一律归拢）

## 3. 交互与状态矩阵

| 状态 | 表现 |
|---|---|
| 默认（未配置） | 数值控件空 + placeholder「沿用默认」；列表显示「全部沿用默认」 |
| 已配置 | 显示数值；列表显示 chips |
| 切换采样模式 | 另一侧**自动清空** + extra 回显「已清空 X 的值（二者只能填其一）」；其值不进 payload |
| 未选中的一侧 | 控件 `disabled` + 灰底，extra：「未选中；其值不会进入提交内容」 |
| 思考=开启 | 展开 budget_tokens 输入，extra 用 `--ws-brand-600` 警示共享预算 |
| 思考=锁死（分类档） | 分段控件整体 `locked`（禁用 + 降透明），extra 说明「C7-d 强制关闭；切其它档位可解锁」 |
| 校验失败 | 字段级红边 + 字段 extra 变红 + `message.error` 展示**后端返回的中文原文** |
| 保存中 | 按钮文案「保存中…」+ `disabled` 防重复提交，完成后恢复 |
| 提交前 | 「提交内容预览」实时显示将发送的字段（未填的不出现），作为验收锚点 |

## 4. 前后端分工（不许在前端重造判据）

- 互斥与值域的**真相源在后端**（`assertTuningParams()`，契约 C7-b）；前端只做**预防性禁填**，报错文案一律用后端返回的中文（原型里的文案仅作示意，标注清楚）。
- 未填字段**不进入 payload**（而非传 null），与后端 C7-h「传了才覆盖」语义一致。
- 前端只新增字段透传与展示，不新增业务规则。

## 6. 风险 / 待澄清

1. **`thinking` 并非所有模型都支持** —— hy3 / 非推理模型填了可能被忽略。是否按所选模型动态禁用该控件？（需后端告知能力，字典暂无「是否支持思考」字段）
2. **预设是否入库**：当前设计为「仅填充表单」；若希望记录「谁按什么档位配的」，需另加字段（超出本次范围）。
3. **列表 chips 数量**：参数变多后可能撑宽，超出是否省略为「+N」？（原型未实现，标为未定义项）
4. **`--ws-overlay` / `--ws-shadow-float` 需先入 `tokens.ts` + `tokens.css`**（双文件同步），否则落码会出现裸值。
