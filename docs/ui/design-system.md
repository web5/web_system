## 0. 适用边界与读法

### 0.1 本文件不做什么

- **不承载数值**：所有具体数值的唯一事实源是 `packages/ui/src/tokens.ts`（↔ `tokens.css`，须同值）与品牌端 `apps/kedou-ai-minigram/app.wxss` 的 token 层。本文件只给**判据**与**引用方式**，不抄色值/字号/间距数值（沿用 `docs/ui/README.md` §3 防漂移责任）。
- **不替代端规范**：admin 系判断层仍是 `docs/ui/design.md`；品牌端规则仍是 `.codebuddy/rules/brand-interface/RULE.mdc`。本文件是**跨端的判据总纲**，与二者互补；冲突时：数值 → tokens/端 token；判断条目 → 本文件；端专属细则 → 端规范。

### 0.2 读法（两端分区，勿混用）

| 端 | 覆盖范围 | 主判据源 | 数值源 |
|---|---|---|---|
| **admin 系** | deploy-console / admin / mcp-admin / 内部工具端 | 本文件 + `docs/ui/design.md` | `packages/ui/src/tokens.ts`（`roles.light/dark.*`，CSS 前缀 `--ws-*`） |
| **品牌端** | portal / kedou-ai-minigram | 本文件 + `rules/brand-interface/RULE.mdc` + `docs/ui/ui-design-spec.html` | `apps/kedou-ai-minigram/app.wxss`（`--brand*` / `--page-bg` / `--card` / `--t1..t3` 等） |

> ⚠️ 两套体系并行，**勿混用**（`README.md` §1 已有此警告）。I 维度专判串端。

### 0.3 条目编号与引用

- 条目 ID = **维度字母 + 序号**（如 `E2`、`G4`、`S5`）。评审报告中写作 `[E2]`，可直追本文件。
- 每条含「判据一句话 + 反例/不合格形态 + 适用端」。判据必须**可判真伪**：读到就能回答"这份稿合格吗"，不含"好看""合适"这类无法裁决的措辞。
- 判不到编号的意见 = 个人偏好，评审时降级为「建议」并标注（依 `design-reviewer` §3.1 机制③）。

## 1. 设计原则（P1–P6）

| ID | 原则 | 不合格形态（反例） |
|---|---|---|
| **P1** | 信息优先于装饰：每个模块必须承载信息或操作，装饰性元素不得占位 | 通栏 banner 只放渐变无信息；卡片只为"显得丰富" |
| **P2** | 一致性优先于个性化：同端同类元素（按钮/卡片/状态/页头）形态一致 | 同一系统里两种卡片圆角、两种主操作样式并存 |
| **P3** | 状态必须可见：任何异步/异常/边界都有可见表达 | 请求失败静默、按钮点了没反应 |
| **P4** | 操作必须可预期：用户点之前能预判后果，破坏性尤其如此 | 删除无确认、确认文案不写影响面 |
| **P5** | 密度对齐参照物：与端内参照页同量级，不自创疏密 | 同是列表页，一页 10 行另一页 20 行且行高不同 |
| **P6** | 未定义不脑补：需求未定义的交互路径显式标注待确认 | 自行发明降级行为且不告知 |

## 2. 视觉基线

### 2.1 层级（E1–E5）

| ID | 判据 | 不合格形态 |
|---|---|---|
| **E1** | 层级由「字号梯度 + 字重 + 色阶」三者**组合**表达，三者至少两项协同变化 | 只靠加粗堆叠表达层级（全用 600 字重分主次） |
| **E2** | 一屏只有**一个**主视觉焦点（主操作或主数据），不得出现两个同等权重焦点 | 两个 primary 按钮并排；两个同样大的数据卡抢焦点 |
| **E3** | 字重只用 400 / 500 / 600（`tokens.font.weight`）；品牌端同级 | 出现 300 / 700 / bold |
| **E4** | 字号取字阶（admin：`tokens.font.size` h1/h2/h3/h4/base/caption；品牌端：端内字阶），禁自定义数值 | 出现 15px / 13px 等阶外值 |
| **E5** | 标题层级不跳级（h1 → h2 → h3） | h1 下直接 h3 |

### 2.2 信息密度（E6–E9）

| ID | 判据 | 不合格形态 |
|---|---|---|
| **E6** | 一屏 primary 主操作 ≤ 1（`docs/ui/design.md` §2 第 1 条） | 页头右上 + 表格区左上各一个 primary |
| **E7** | 行高、表头字号、同屏条目数与本端参照页同量级（admin 参照 `ServiceManager.vue`；品牌端参照该模块主流程页） | 明显更疏或更挤，与同类页并置即现差异 |
| **E8** | 行内操作 > 3 个折叠进 dropdown / 更多 | 操作列铺满 5 个按钮 |
| **E9** | 数据密集区禁插入无信息量装饰模块 | 表格上方插无数据 banner |

### 2.3 间距与对齐（F1–F5）

| ID | 判据 | 不合格形态 |
|---|---|---|
| **F1** | 间距取自间距阶梯（admin：`tokens.space`；品牌端：8rpx 基准，细调允许 4rpx 步进），禁阶外随意值 | 出现 13px / 7rpx 这类无法归阶梯的值 |
| **F2** | 同级等距、层级递增：同组元素间距相等，分组间距 **>** 组内间距 | 组内 24、组间也 24（层级不可辨） |
| **F3** | 卡片内边距四周相等；列表行左右对齐到同一基线 | 卡片左右 padding 不等；列表行首列参差 |
| **F4** | 数字列开 `tabular-nums`；端口 / ID / 路径 / 代码用等宽（admin `.ws-mono`） | 数字列跳动；ID 用比例字体 |
| **F5** | 禁以空行 / 多个换行 / 透明占位撑间距 | 连续 `<br>` 或空 div 拉距离 |

> 品牌端存量存在非 8 倍数的历史间距值（如 26/22/18rpx）。**新稿按阶梯走**；改动存量时"就近归拢"到阶梯即可，不要求全量返工。

### 2.4 色彩语义与对比度（G1–G6）

| ID | 判据 | 不合格形态 |
|---|---|---|
| **G1** | 色值只引 token（admin：`--ws-*` / `uiTokens`；品牌端：`--brand*` / `--page-bg` / `--t1..t3` 等）；**禁裸 hex / rgba**（原型 `:root` 与端 token 定义层除外） | 业务样式里写 `#F97316` |
| **G2** | 颜色**只编码语义**（success / warning / error / info + brand）；**类型、枚举不配色**（`design.md` §2 第 9 条） | 给"环境=dev/test/prod"各配一种色 |
| **G3** | 对比度过 AA：正文 ≥ 4.5:1；大字（≥18px，或 ≥14px 且 500/600 字重）≥ 3:1 | 灰字压浅灰底读不清 |
| **G4** | 品牌橙作**文本/选中态**时用深档（admin：`brand[600]` 档；品牌端：`--brand-txt`）；纯品牌橙 `#F97316` 在白底对比度仅 2.9:1，**不得用作正文文本色** | 白底上用 #F97316 写标题/链接 |
| **G5** | hover / active 走既定阶梯（admin：`--ws-bg-hover` → `--ws-bg-active`），禁自定义灰、禁散写 rgba | hover 写 `rgba(0,0,0,0.04)` 或随意灰 |
| **G6** | 语义色不得用于"强调好看" | 用 error 红标重点文字 |

### 2.5 圆角 / 描边 / 阴影（G7–G9）

| ID | 判据 | 不合格形态 |
|---|---|---|
| **G7** | 圆角取圆角档（admin：`tokens.radius` sm/md/lg/pill）；同层级元素圆角一致 | 同为卡片却 6px 与 12px 混用 |
| **G8** | 分隔优先 hairline / 边框（admin `.ws-hairline`），不靠阴影堆层级；阴影取 `tokens.shadow.card` / `popover` | 每个卡片都加自定义大阴影 |
| **G9** | 禁多重阴影叠加造"浮起" | 同一元素 3 层 box-shadow |

## 3. 交互模式库（选用判据 + 锚点约定）

### 3.1 模式选用（M1–M6）：何时用 / 何时禁用

| ID | 模式 | 何时用 | 何时禁用 |
|---|---|---|---|
| **M1** | 表格 + 筛选条 | 数据列表、需多条件检索 | 条目 < 5 且无需检索（用列表卡） |
| **M2** | Tabs / RadioGroup 切换 | **互斥且固定选项**：≤4 用 tabs；5 或空间紧用 radio-group | 选项动态 >5、需搜索（用 select）；表单内字段（豁免） |
| **M3** | 分步条（steps） | 多步表单、需回退 | 单步可完成；或步骤间无依赖（用分组表单） |
| **M4** | Drawer | 二级详情/表单，需保留上下文 | 需与主内容对照（用并置）；弹窗内套弹窗（禁） |
| **M5** | Modal.confirm | 破坏性操作二次确认 | 非破坏性操作也拦一道 |
| **M6** | 折叠 / 截断 + 渐隐 | 长内容超阈值需收起 | 阈值内短文本（折了反而藏信息） |

> M2 的适用边界沿用 `docs/ui/design.md` §2 第 10 条（含"表单内选择字段 / 复合查询表单"豁免）。

### 3.2 锚点约定（A1–A4，服务 D3 实现一致性评审）

| ID | 判据 |
|---|---|
| **A1** | 原型稿中的**关键结构元素**打 `data-dr="<key>"`（页头、主操作、状态区、列表容器、主表单等）；实现中同位置打同名锚点 |
| **A2** | 只对关键结构打，**不逐元素打**（避免噪音与维护负担） |
| **A3** | 原型与实现锚点须**同名同语义**；改名/删除须同步改两侧并在评审报告登记 |
| **A4** | **存量页面也补**：清单驱动分批（见 `docs/ui/anchor-backlog.md`，共 129 个界面文件），批次序 = admin 主流程 → portal 主流程 → 小程序主包 → 分包低频；比对开关 `DESIGN_ANCHOR_MODE` 由 `off` → `warn`（观察一轮）→ `scoped`（按批 error）→ `strict`（`specs/design-reviewer/design.md` §3.7.1 / Q4–Q5） |

## 4. 状态矩阵（S1–S9）

> 每个"会产生结果的操作"必须覆盖；**不许只做成功路径**（`design.md` §3）。

| ID | 状态 | 判据 | 不合格形态 |
|---|---|---|---|
| **S1** | 加载中 | 骨架屏或 loading 可见 | 白屏等待 |
| **S2** | 假 loading | **禁**：无 loading 状态却人为延迟展示 | 设 300ms 假延迟 |
| **S3** | 空态 | **原因 + 出路**（"暂无部署记录，点右上发起首次部署"） | 裸"暂无数据" |
| **S4** | 失败 | 错误文案 + 可重试路径（重试按钮或刷新入口） | 静默失败 / 只 console 报错 |
| **S5** | **无权限** | 显式说明无权限 + 唯一出路（申请入口或返回）；**禁空白、禁 silent 隐藏**后无解释 | 页面半截、按钮消失但无说明 |
| **S6** | 破坏性操作 | 必二次确认，文案写明后果（影响面 / 是否可恢复） | 点了直接执行 |
| **S7** | 禁用态 | 禁用时 tooltip 说明原因（"需先启用环境"） | 无声禁用 |
| **S8** | 进行中 | 锁重复提交（saving 锁）+ 按钮 loading | 连点产生重复请求 |
| **S9** | 弹窗嵌套 | 弹窗内不套弹窗；二级表单改 step 或抽 drawer | 三层 modal 叠加 |

## 5. 文案与语气（H1–H6）

| ID | 判据 | 不合格形态 |
|---|---|---|
| **H1** | 按钮**动词开头**（"重启""新建""发起部署"） | "提交一下""确定吧" |
| **H2** | 禁冗余敬语与客套（"您""亲爱的""感谢您的使用"出现在操作位） | 按钮写"请您点击提交" |
| **H3** | 副标题一句话说明用途，禁产品宣传腔 | 副标题写营销 slogan |
| **H4** | 错误文案 = **出了什么问题 + 怎么办**；禁只报错误码或只说"失败" | "操作失败" / "Error 500" |
| **H5** | 术语一致：同一概念全文同一词（"环境"不一会儿叫"环境"一会儿叫"实例"） | 同页混用两个词 |
| **H6** | 交付稿禁 lorem / TBD / "测试"占位堆砌；占位须显式标注待补 | 正文塞 lorem ipsum |

## 6. 端差异对照表（I1–I5）

| ID | 维度 | admin 系 | 品牌端 |
|---|---|---|---|
| **I1** | 主色与文本档 | 主橙取 `brand[500]`；文本/选中态用深档 | 主色 `--brand`；文本/选中态用 `--brand-txt`（深档，过 AA） |
| **I2** | 页面底与容器 | `bgPage` / `bgSurface`（CSS `--ws-*`）；hairline 描边 | `--page-bg` 浅暖底 + `--card` 白卡；`--line` 分隔 |
| **I3** | 密度与圆角 | 后台密度，圆角档小（sm/md） | 卡片大圆角、留白更松（移动优先） |
| **I4** | 单位与字阶 | px，`tokens.font.size` 字阶 | rpx，端内字阶；适配安全区（`env(safe-area-inset-bottom)`） |
| **I5** | 图标与原生能力 | SVG（tabler / antd icons），**禁 emoji** | 同禁 emoji；平台原生能力（分享/授权/支付/订阅消息）须**占位 + 标注真机语义**，禁伪装已实现 |

**串端判定（评审直接引用）**：admin 稿出现品牌端 token 名（`--page-bg` / `--brand-txt` / `--card`）或反之；桌面稿冒小程序胶囊 / TabBar；H5 稿冒充原生能力 → 均为 `I5` 阻塞项。
