任务 高级 环境变量
任务 = 有序的动作列表，从上到下依次执行：先「脚本」完成主体工作，再「工具」调用平台能力。可增删、排序。

条件满足 → 执行该任务；不满足 → 跳过。无条件的任务恒执行；发布这类多选一用互斥条件。
语法：KEY == 值 / KEY != 值，多条件用 &&；含空格的值用引号包裹。
变量：DEPLOY_ENV MODULE_KEY MODULE_TYPE BRANCH COMMIT_ID、流水线变量与配置中心值。
示例：DEPLOY_ENV == prod　DEPLOY_ENV != local && MODULE_TYPE == backend
任务级环境变量：执行该任务脚本时注入进程，可在脚本里用 $KEY 引用。
