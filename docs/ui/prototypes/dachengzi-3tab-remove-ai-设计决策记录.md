## 一、目标端确认

- **目标端**：微信小程序（`apps/dachengzi-minigram`）。
- 原型载体：HTML 模拟壳，按小程序宿主元素画 —— 状态栏 + 导航栏（标题居中 + 右上胶囊占位 `54×26`）+ 底部 TabBar（3 tab）。非 Web 端不做跨端响应式，不产出 WXML。
- 一稿聚焦一个主目标端（小程序），不混端、不串壳。

## 二、整改删了什么（对齐已落地代码，非「整改前」）

| 删除面 | 原型对应处理 |
|---|---|
| AI 对话 / 翻译闭环（D 组整组帧） | 不保留任何对话/翻译屏、入口、设置。原型 9 屏中无 chat / translate / 翻译记录 / 翻译设置 |
| 三种显示模式 / 点句译文 / 生词查词 / 参考译文 / 习题 / 导读问题 | NCE 详情屏只留「英文课文 + 逐句朗读 + 逐句收藏」，无全文朗读控制条 / 刻度条 / 暂停继续停止 |
| 生词本 | 改名「收藏」，我的列表行、导航标题、空态按钮（去学课文）全部按「收藏」口径 |
| AI 语义文案 | 全文（产品 UI）无「AI / 对话 / 翻译 / 讲解 / 生词本 / 个人助理 / 语音输入」；「内容由 AI 生成 / 已依法完成大模型与算法备案」合规行已删 |
| 品牌 | 统一「大橙子英语」（app.json 已定标题），不再出现「一个橙子个人助理」「一个橙子助理」 |

## 三、三 tab 目标态（屏结构）

| 屏 key | 页面 | 内容 |
|---|---|---|
| `home` | 首页 | 问候 hero + 今日一句 + 常用功能（默认 NCE，可加收藏）+ 更多功能 ›（跳发现） |
| `discover` | 发现 | 全部功能列表（NCE + 收藏），每项带「+ 添加 / 已添加」开关，即时联动首页 |
| `mine` | 我的 | 资料卡 + 课文学习进度 + 收藏 + 设置 + 用户协议与隐私政策 + 关于与免责 |
| `nce` | NCE 课文目录 | 进度 + 课文列表（去「N 题」元信息） |
| `ncedetail` | NCE 课文学习 | 字号 A-/A/A+（保留）+ 逐句（点读 + 句末 ☆ 收藏）+ 上一课/下一课 |
| `collection` | 收藏 | 收藏列表（英文 + Lesson 出处 + 译文 + 删除）/ 空态「去学课文」 |
| `settings` | 设置 | 外观/存储/关于/账号（无「功能」分区、无「发现设置」入口） |
| `about` | 关于与免责 | 品牌「大橙子英语」+ 中性化免责 |
| `agreement` | 用户协议与隐私政策 | 「学习数据：课文学习进度、收藏」 |

## 四、平台原生能力占位（不假装已实现）

| 能力 | 原型处理 |
|---|---|
| 登录授权 | 「去登录 / 请先登录」弹层，标注「登录由小程序静默完成（wx.login），无需额外授权」；真机行为以小程序规范为准 |
| 逐句朗读（TTS） | 原型用「点句高亮 + 句首播放态」模拟（`InnerAudioContext` 播放，非录音）；不实现真实音频 |
| 分享 / 转发 | 右上胶囊（…/转发）为占位视觉，未实现真机转发 |
| 圆角风格 / 清除缓存 / 退出登录 | 设置页点击 toast「落地以小程序真机为准」占位 |

## 五、演示控件状态矩阵选型

- **方案 A · 逐屏分支块**（demo-control-panel §5.2）：`normal` / `empty` 两态。
  - `collection` 有真实空态（还没有收藏 → 去学课文）；`home` 有「无常用功能」空态；其余屏 `empty` 为诚实占位（「本屏为静态信息页」），保证切数据态时任何屏都不致空白。
- **角色**：`guest`（未登录）/ `member`（已登录），经 `data-need-role` 驱动（首页问候名、我的资料卡两态）。
- **开关真生效**：发现页「+ 添加 / 已添加」真实改写 `pinned` 集合并重渲染首页常用功能卡（对应 `features:updated` 广播语义），不是假开关。

## 六、质检结论（ux-review-checklist.md 逐条）

**机检**：`check-demo-panel.mjs` ✔ 通过（`data-demo-ctl` / 屏注册表对账 / 场景包 ≥3 且含 role·screen·state / 数据态 CSS 分支 / `@media print` 隐藏 / 收起 / 复位 全过）。

**A 信息架构**：通过。9 屏全覆盖，每屏可达、有返回路径（二级页 back → PARENT 映射；tab 页互切）。
**B 任务流闭环**：通过。主路径 首页 → NCE → 详情 → 逐句朗读/收藏 → 我的 → 收藏 闭环；异常分支（收藏空态、登录守卫）有明确去向。
**C 状态矩阵**：通过。收藏空态 / 首页空态有唯一恢复入口；完成态（收藏/添加常用）有 toast 反馈。
**D 操作与确认**：通过。逐句收藏 catchtap 语义（☆ 不冒泡到点句朗读）；删除收藏即时减少计数，归零自动切空态。
**E 视觉 Token**：通过。蓝系 token（`--brand:#2563EB` / `--brand-mid:#3B82F6` / `--brand-tint:#EFF6FF`）白底浅色；无裸 hex 出 `:root`、无 emoji、图标全内联 SVG、间距 8 倍数。
**F 可访问性基线**：基本通过（遗留项见下）。可点击区多为可聚焦元素；句末 ☆ / 播放 / 删除为 `<span>` 语义（原型阶段可接受，落地转 button/catchtap）。
**G 内容真实性**：通过。真实业务文案（Lesson 4 课文、收藏句子），无 lorem / 占位堆砌。
**H 目标端一致性**：通过。小程序壳（胶囊/TabBar）；平台原生能力占位 + 标注；未混入 WXML/落地代码。
**I 未定义项显式标注**：通过。待确认项以 `data-anno` D1–D5 标注，见 §八。
**J 演示控件与自解释性**：通过。L1 完整（稿头 + 场景包 6 + 角色 + 数据态 + 屏直达 + 标注层 + 复位 + 收起）；控件在壳外画布右下（宽 240px），未进手机壳内部；`H` 收起、`@media print` 隐藏、弹层打开时控件降透明；待确认计数从 DOM 数出。

**遗留项（不阻断交付）**：
1. 句末 ☆ / 播放 / 删除微按钮为 `<span>` 语义（非 `<button>`），落地时应转 button + `catchtap`。
2. 「上一课 / 下一课」在原型内为静态导航示意（点击回详情自身），真实 96 课切换按册取相邻课，未在原型展开。
3. 逐句朗读为视觉模拟（无真实音频），真机验收需微信开发者工具实跑（对齐规格 §9）。
