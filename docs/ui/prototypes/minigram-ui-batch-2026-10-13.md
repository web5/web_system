# kedou-ai-minigram UI 批次规格（2026-10-13）

本文件是 `fix/minigram-wave-icon` 分支**全部 UI 改动的原型/规格依据**，集中落库一次，
供后续各实现 commit 以 `Proto: <本 commit sha>` 引用（§3.8）。

作用域：`apps/kedou-ai-minigram`（微信小程序端）。

## 1. 语音输入 icon（L1 定稿）

- **几何**：半弧端点严格同 x 镜像；核心圆点 `r=2.5`，内弧 `r1=7.25`，外弧 `r2=11.55`，
  张角 `span=48`，描边 `sw=2.3`（参数真源：`scripts/gen-mic-icon.py` 的 `PARAMS`）
- **三态**：`idle`（中性灰）/ `current`（品牌橙）/ `white`（反白，用于橙底按钮）
- **资产**：SVG 为唯一真源，按 27 / 54 / 96 / 288 四尺寸光栅化
  （`prototype/assets/voice-icon/`、`assets/voice-icon/`）
- **规范**：`docs/语音输入icon设计规范.md`（11 条）

## 2. 自定义导航四元素对齐（顶栏）

- **基准**：以原生胶囊矩形为**唯一基准**（水平 + 垂直），不再用 44px 区间推算
- **坐标系**：`capsuleTop` 存**绝对页面坐标**（`menuButtonRect.top`），不得减状态栏高度
- **光学补偿**（几何对齐 ≠ 视觉对齐，文字视觉重心偏高）：
  `title +3px` / `新增对话 +2px` / `对话记录 +1px` / `返回 0`
- **`title` 字重**：400（不加粗）

## 3. 对话页空态

- 新建对话**不插缺省 AI 气泡**，`chatMessages` 初始为空数组
- 背景面板加缺省欢迎语：**「有什么想聊的，直接说」**，浅灰 `--t3`、26rpx，
  位置**偏上 1/3**（`margin-top: 300rpx`），发出首条消息即消失
- 欢迎语走 `wx:if` 条件渲染，**不进消息列表**（不落库、不参与历史合并）
- **移除**开场推荐语（帮我翻一句话 / 看看合同风险 / 今天该做什么）

## 4. 输入栏契约

顺序：`＋ → 声波（按住说话） → 输入框 → ↑`；pill 白底外框 + 细边 + 柔影；
`＋`/`🎤` 为 76rpx 浅橙底圆钮，`↑` 为 76rpx 实心橙底白字；mic 位图 44rpx。

## 5. tabBar 契约

- 三项：对话（普通页，`navigateTo`）/ 发现 / 我的（后两者 tab 页，`switchTab`）
- **高亮**：页面 `onShow` 显式登记（组件每页独立实例，禁止自推导）
- **对话页返回栈**：返回（右滑手势 / 返回按钮）**始终回到欢迎页**；
  实现为「进对话页时保证其下一页是欢迎页」（`utils/tabbar.ts` 的 `openChat`）

## 6. AI 回复渲染

- markdown → `rich-text` nodes；文本节点必须 `{type:'text', text}`（裸字符串不合法）
- 色值硬编码（rich-text 为隔离 webview，拿不到 CSS 变量），单位 px（不认 rpx）
- 折叠用 `max-height` + 渐隐（`line-clamp` 对节点树失效）
- 朗读 / 复制经 `mdToPlain` 剥离语法符号

## 7. 音乐卡：渠道选择与降级（2026-10-13 追加）

问题：点「去 QQ音乐听」只有复制动作，跳不出去。定位到渠道按 sort 取、与端能力无关。

规格：

- **渠道由端上自选**，不下发单一渠道了事：`card.providers` 带全量可用渠道，端按自身能力挑
  - mini_program → 小程序可跳（PC 跳不了）
  - h5 → PC 可开新页；小程序 web-view 受业务域名限制打不开 → 降级
- **优先级**：能跳 > 能复制链接 > 只能复制歌名
- **按钮文案必须与实际行为一致**（此前一律写「去 XX 听」，实际只复制 → 误导）
  - 能跳：`去 QQ音乐听`
  - 只能复制：`复制链接` / `复制歌名`
- **卡片底部说明随能力变化**：能跳才说「跳转后…播放」，只复制就说「粘贴到浏览器打开」
- 跳转失败（用户取消 / 目标不可用）同样降级，不静默失败
- 老历史（无 providers 字段）兼容：退回单一 provider

无新增视觉元素，仅文案与行为分支变化。
