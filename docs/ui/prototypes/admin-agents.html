防抖函数把高频触发合并成一次执行，核心是「清旧定时器 → 重新计时」。

js
function debounce(fn, wait = 300) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), wait);
  };
}

注意两点

  1. 1定时器放闭包，避免全局污染；
  2. 2组件卸载时 clearTimeout，防内存泄漏。

有风险，条款本身不无效——风险在于 你把定价权交给了房东，且没有上限。

《民法典》第 510 条合同生效后，当事人就价款等内容没有约定或约定不明确的，可以协议补充；不能达成补充协议的，按照合同相关条款或者交易习惯确定。

建议争取两处修改

  1. 1写死递增上限：不超过上一年度租金的 5%，或锚定 CPI；
  2. 2删掉「乙方不得异议」：改成「双方协商一致」，保留谈判空间。

如果房东连补充协议都不签，说明后续争议概率不低，建议换房。▍
