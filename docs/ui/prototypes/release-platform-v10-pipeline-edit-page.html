交互演示提示
① 列表页右上「状态演示」可切换 正常 / 加载 / 空态 / 错误 四态。
② 点流水线行进详情；右上「编辑」进入独立编辑页（面包屑返回详情），「发起发布」开发布抽屉。
③ 编辑页：内置名/删除禁用（悬停 tooltip）；改 key 即时校验；点 script 节点配命令（多操作 + 变量 chips + 按模块预览）。
④ 点「保存」→ 按钮 loading；有未保存改动点「取消」/ 面包屑 / 侧栏离开 → 弹「放弃修改」确认。
⑤ 当前运行点流程图节点或「查看日志」→ 日志抽屉（阶段切换）；回滚 / prod 提交均有二次确认。
