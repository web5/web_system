场景：
完成 执行中 失败 待审批 跳过（灰） 未执行 任务卡：绿色只填序号竖条（数字反白）、卡片白底；连线着色见下方 v2 提案
结构（2026-09-22 已确认）：① 步骤卡紧凑化（名称 / 命令，无序号）；② 连线 = 任务行 SVG 测量 （主线在前一列任务中线、列间分叉竖线、箭头指向每个任务中线），与编辑页同构；③ 跳过 = 灰色，不复用成功色。
连线绘制定义（2026-09-23 · 唯一判据源） —— 相邻两列之间的一条连接由 4 段构成， 每段有明确的几何与状态归属（实现见本文件 drawRunWires()，方案见 specs/pipeline-flow-color/design.md §2.5）：
段几何（怎么画）归属（看谁的状态）颜色
L1 主线横线从进入侧列首个任务卡右侧中点 → 水平到分叉 X（mx = 两列中点） 目标列步骤的聚合状态（该列所有分支的合并：有成功分支时成功覆盖跳过/失败等， 聚合规则与步骤卡边框同源）—— 边的颜色 = 目标（下一个）节点的颜色（a→b 看 b、a→c 看 c） 聚合状态：完成 → 绿 / 执行中 → 品牌色 / 失败 → 红 / 待审批 → 橙 / 跳过 · 未进入 → 灰
（支线颜色 = 各目标任务自身，见 L3/L4）
L2 分叉竖线目标列多任务时才有：mx 处，从最高任务行中线 → 最低任务行中线 同 L1（目标列聚合）
L3 支线横线mx → 每个目标任务卡左缘中点（每任务一条） 该目标任务自身 完成 → 绿 / 失败 → 红 / 执行中 → 品牌色 / 待审批 → 橙 / 跳过 · 未执行 → 灰
L4 箭头支线末端的 chevron，尖点落在任务卡左缘
特例：目标列单任务且与进入侧任务同高 → 无 L2/L3，L1 直接接到任务卡 + 箭头（色同 L1）。 任一侧无任务卡 → 不画线。线型一律实线 2.5px；虚线只用于任务卡边框表达「跳过」。
任务的六种状态（taskStates 落库，`ProgressFlow.vue` taskStateOf）： ① 完成（执行成功，含审批通过）② 失败（动作失败 / 审批拒绝）③ 执行中（已开始未结束） ④ 待审批（审批挂起）⑤ 跳过（条件不满足 / 停用 / 超时按跳过 —— 没有真正执行） ⑥ 未执行（还没轮到，无执行记录）。另有「已取消」（取消信号命中，按灰处理，待拍板④）。
待拍板：② 失败支线标红 ③ 执行中/待审批支线着色 ④ 已取消颜色 —— 方案见 specs/pipeline-flow-color/design.md。确认后按此落码 apps/deploy-console/src/components/pipeline/ProgressFlow.vue 的 drawWires()。
