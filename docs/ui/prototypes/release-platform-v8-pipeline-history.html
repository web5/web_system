调整落法
流水线菜单 = 所有流水线列表侧栏「流水线」进入列表页（名 + key + 适用模块 + 最近运行 + 最近版本 + 执行次数）；点行进详情
详情第一个 tab = 当前最新运行情况展示最近一次实例：状态、环境/模块/版本、耗力、执行流程图（节点态着色）、失败时日志尾部 + 重试、成功时可「回滚到此版本/再次发布」
第二个 tab = 执行历史表列含版本；行内操作：回滚到此版本、详情、重试
取消独立「版本与回滚」tab回滚操作下沉到执行历史行内；legacy 历史产物表跟在执行历史下方
保留的后置 tab「编排与命令」（定义编辑）、「发起发布」（环境选择 + 身份预览）
模块页只展示「环境 × 当前版本 + 时间 + 回滚」，不标注所属流水线；「发布脚本」tab 已移除
待你确认的 4 点（原型默认方案）
#问题原型默认方案
1「当前运行」是否只显示最新一次 是：只显示最新一次；要看更早的走「执行历史」下钻详情（避免同页两个实例视图）
2执行历史是否按模块筛选 是：全局线服务多模块，默认「全部」+ 模块下拉过滤
3回滚入口是否保留在模块页 保留（模块页可滚到该环境任意版本、含 legacy）；若希望"回滚统一去流水线"，此处改为跳转
4tab 数量与顺序 当前运行 → 执行历史 → 编排与命令 → 发起发布（4 个）；若觉得"编排与命令"更该靠前，可调为 编排与命令 → 当前运行 → 执行历史 → 发起发布
交互演示提示

④ 「发起发布」里改环境 / 模块 / commit → 身份预览实时变化。
