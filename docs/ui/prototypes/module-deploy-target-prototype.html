设计要点（本稿要确认的）

1. 部署目标是模块的自有属性，环境不参与路径决策 —— 所以一条流水线可以跑多个环境。
2. 产物先入「产物区」，部署时才落到「部署目标」—— 产出与生效解耦。
3. CDN 时不填密钥，凭据走配置中心；manifest 输出绝对 URL（本地/远程仍相对路径）。
4. 产物 URL 含版本号 → 天然避缓存，切指针即生效，无需 purge。
