圆角双风格 · 外观偏好

把「圆角」从尺寸档（sm/md/lg）收敛为语义档（chip / control / card / pill），数值由用户偏好决定。 柔和 = 现状默认（零视觉变化）；清爽 = 小圆角新档（2px）；直角 = 无圆角新档（0px）。三档都是用户可选的圆角风格。两端基线统一为 4 / 6 / 8px（品牌端落地 8 / 12 / 16rpx）。

语义圆角档 · 元素封闭映射

每个元素有且只有一个归属；未列出的元素视为「待确认」，不得自行归类

语义档覆盖元素（封闭清单）柔和（默认）清爽 / 直角
--r-chip 标签、徽标、状态点外的微角、代码片段背景 4px (8rpx) 2px / 0px
--r-control 输入框、按钮、选择器、下拉、分段控件、日期选择、上传按钮 6px (12rpx) 2px / 0px
--r-card 卡片、面板、弹窗、抽屉、列表容器、表格容器、Popover/Dropdown 面板 8px (16rpx) 4px / 2px
--r-pill 胶囊按钮、开关（轨道 + 圆钮）、标签式筛选片 9999px —— 风格无关，两种风格都不变
不参与切换 border-radius:50%（头像、状态点、圆形图标）· border-radius:0（气泡贴边角、贴边抽屉）· 进度条/骨架条（待确认） 保持字面值，不受风格影响

机制：<html data-radius="soft|crisp|sharp"> 直接覆盖尺寸档 --ws-radius-sm/md/lg 的值， 语义档是它们的别名 —— 因此并行「新规范整改」把裸值换成的尺寸档引用，自动获得风格切换能力、无需回改。

D

例外与实现要点

不纳入风格切换的部分，以及各端落地必须处理的坑

不参与切换（固定值）

  • border-radius: 50% —— 头像、状态点、圆形图标
  • border-radius: 0 —— 聊天气泡贴边角、贴边抽屉
  • --r-pill —— 胶囊、开关（轨道 + 圆钮）
  • 进度条 / 骨架条 —— 待确认（暂按字面值，不归入 chip）

各端实现坑（必须处理）

  • adminantd borderRadius 来自 JS 常量（antd-theme.ts），只改 CSS 变量 不生效 → 必须同时改 ConfigProvider themeConfig 并 watch
  • 小程序page 无法绑 class → 只能挂各页根 <view class="page {{radiusClass}}">（30 处）；app.wxss 目前无任何圆角 token，需先建变量层
  • deploy-console无偏好 store（仅被动读主题），需新建载体；外壳固定深色，仅圆角跟随
  • 首帧偏好由 JS 写入根属性，清爽用户首屏会以柔和渲染后跳变 → index.html 需内联预置属性
  • 持久化后端无用户偏好接口 → 本期各端本地存储，跨端不同步
