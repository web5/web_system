v4 核心变更
platform 态version / pointer —— 发布语义真相源，UI 置灰 + API 400 拒绝编辑
script 态check / build / upload / restart / verify / cleanup —— 必须配脚本，未配（且未禁用）即 fail-fast
git 内置pull 恒由平台执行（fetch/checkout/reset/clean + lock 指纹），脚本只作 hook 附加
参数不再猜测PM2_NAME / PORT / PUBLIC_PATH / ARTIFACT_DIR 显式注入，优先级：配置中心 → 模块注册表 → pm2_env
结果回传脚本写 $WS_RESULT_FILE（JSON），平台按白名单合并进 result
退出码0 成功；非 0 失败并触发 rollbackOnFailure；continueOnError 仅允许 cleanup 类
超时按节点独立配置（check 60 / build 600 / upload 300 / restart 120 / verify 120 / cleanup 60）
日志脱敏注入的密钥变量值在落库前统一掩码为 ***
脚本指纹scriptHash 入实例与审计，回答「当时跑的是哪份脚本」
回滚漂移回滚用最新脚本发旧代码 → 标记 scriptDrift=true
