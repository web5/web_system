新建字典

字典结构（基本信息 + 字段定义）在此页维护；记录数据在列表页用抽屉维护
基本信息
只能包含小写字母、数字和下划线，且以字母开头
停用后业务侧视为空字典
字段定义 决定明细表列与记录表单控件；length 为长度上限（写库强校验 + 输入前置拦截）
#字段名标签 类型长度必填 枚举项 / 默认值操作
暂未定义字段
记录将只含 Value / 名称 两个字段
保存时整体提交字段数组（覆盖式）。删除字段只丢这一列的值，不删数据行。
删除字典
连带删除字段定义与全部记录，不可恢复；已引用该字典的服务会回落至环境变量 / 内置默认值。
