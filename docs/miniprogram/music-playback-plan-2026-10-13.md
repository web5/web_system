## 1. 现状与根因

### 1.1 数据现状（prod 库 `172.16.16.10/web_system`，2026-10-13 查）

| id | code | name | app_id | entry_type | search_template | sort |
|---|---|---|---|---|---|---|
| 1 | qqmusic | QQ音乐 | `PENDING_QQMUSIC`（占位） | mini_program | — | 100 |
| 2 | qqmusic_h5 | QQ音乐 | NULL | h5 | `https://y.qq.com/n/ryqq/search?w={keyword}` | **10** |

### 1.2 断链在哪

```
resolveProvider()  取 sort 最小 → 第 2 行 h5
    ↓
小程序端拿到 h5 渠道
    ↓
h5 在小程序里打不开（web-view 受业务域名限制，y.qq.com 配不进）
    ↓
onPlay 只认 mini_program → 走降级 → 复制歌名
```

**隐蔽点**：即使把第 1 行 app_id 换成真值，小程序**仍然**拿不到它（sort 更小的 h5 一直抢在前面）。这个不改，填了 appid 也没用。PR #332 已解决这一点。

### 1.3 已落地的修复（待合入）

- **PR #332**：后端 card 增发 `providers`（全量渠道）；小程序新增 `pickProvider`，按 `jump > copy-link > copy-name` 自选；按钮文案随能力变化（不可跳时显示「复制链接」/「复制歌名」）；降级复制内容升级为已渲染的搜索链接；跳转失败同样降级不静默。
- **PR #334**：`sendWith` 入列用户消息漏生成 rich-text nodes → 刚发的消息空白（与音乐卡无关的独立回归）。

### 3.3 代码骨架（文档到手后据此接线，均为待验证写法）

**① `app.json` 声明插件**

```json
{
  "plugins": {
    "kugou": {
      "version": "latest",
      "provider": "wx4f38007b839da9d3"
    }
  }
}
```

**② 数据行：`music_providers` 增 `kugou_plugin`**

实体已预留（`code` 注释写的是 `qqmusic / kugou_plugin`，`entryType` 注释已含 `plugin`），只差数据：

```sql
-- ⚠️ prod 库，执行前须经确认；appid/appkey 用 Step 1 拿到的真值
INSERT INTO music_providers
  (code, name, app_id, entry_type, icon, sort, enabled)
VALUES
  ('kugou_plugin', '酷狗音乐', '<插件appid>', 'plugin', NULL, 1, 1);
```

如需 appkey，先确认是否能复用现有列；不能则加 `app_key` 列（migration + 实体同步）。

**③ 后端 `MusicService.isReady` 明确 plugin 口径**

```
mini_program：appId 非空且非 PENDING_* 占位
plugin：appId 非空且非占位（如需 appkey 则两者都要有）
h5：searchTemplate 非空
```

**④ 小程序 `music-card` 增 plugin 分支**

在 `pickProvider` 里把 `plugin` 排到最高优先级（站内播放 > 跳出）：

```
plugin（站内播放） > mini_program（跳转） > h5（复制链接） > 复制歌名
```

按钮文案：`在酷狗播放`。插件页跳转用 `wx.navigateTo({ url: 'plugin://kugou/...' })` 或挂插件自定义组件（**具体形态等文档**），失败同样降级。

### 3.4 风险

1. 现有文档多为 2020 年前后，插件**是否仍对新主体开放申请**要实测（服务市场页仍在线，信号偏正面）。
2. 插件**可能收费**，服务市场页未标价，开通时会看到。
3. 站内播放意味着音频能力进小程序，**审核口径可能变**（涉及《网络文化经营许可证》的由酷狗承担，但需在小程序类目/用途说明里写清）。

## 4. 兜底：QQ音乐小程序跳转

拿 appid / 页面短链（手机上操作，10 秒）：

> 微信 → 发现 → 小程序 → 搜「QQ音乐」打开 → 右上角「…」→ 「发送给朋友」（**别真发**），上方那串链接长按复制；有「复制链接」更快。「更多资料」里的 AppID（wx 开头）也行。

```sql
-- ⚠️ prod 库，执行前须经确认
UPDATE music_providers SET app_id = '<真值>' WHERE code = 'qqmusic';
```

改完前端无需再改（#332 的 `pickProvider` 会自动选中它），按钮变回「去 QQ音乐听」并真跳过去。

若只拿到页面短链，走 `wx.navigateToMiniProgram({ shortLink })`，需要实体加一列存短链。
