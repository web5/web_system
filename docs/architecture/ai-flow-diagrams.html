读法与口径怎么读这三张图

  • AI 子系统架构图：看「职责分层」——谁编排、谁执行循环、能力怎么挂、模型怎么换、数据落在哪。
  • Agent 运行主链路：看「一次请求怎么走完」——每个 SSE 事件在哪个阶段产出、哪里会失败、失败怎么兜住。图中青色虚线框是子 Agent 委派的递归展开层：子 Agent 走的是同一条链路，只是换一套定义与上下文，且过程事件折叠不上浮。
  • 知识链路：看「知识从哪来、怎么被 Agent 用到、质量怎么量」——当前缺口是召回率未测与golden 集未版本化。
