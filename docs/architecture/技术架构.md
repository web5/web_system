## 1. 项目概览

**Web System** 是一个全栈 Web 应用平台，包含管理后台、少儿教育门户、微信小程序、配套后端微服务，以及 **MCP 平台**（把后台服务零代码接入 MCP 协议供 AI 客户端调用）。项目采用 **pnpm workspace monorepo** 管理多应用、多服务的代码和依赖。

```
web_system/
├── apps/                      # 前端应用
│   ├── shell/                # 微前端基座（提供 window.__SHARED__ + 版本 manifest）
│   ├── portal/               # 少儿教育门户 (Vue3，/portal/)
│   ├── admin/                # 管理后台 (Vue3，/admin/)
│   ├── deploy-console/       # 运维控制台独立 SPA（/console/）
│   ├── mini-app/             # 微信小程序（主端）
│   └── mini-contract/        # 微信小程序·合同翻译官 (原生 + TS)
├── servers/                   # 后端服务（12 个 pm2 进程）
│   ├── gateway/              # API 网关 (NestJS，:6000)
│   ├── auth-service/         # 认证服务 (NestJS，:6101)
│   ├── user-service/         # 用户服务 (NestJS，:6002)
│   ├── ai-service/           # AI 服务 (NestJS，:6003)
│   ├── ai-agent/             # AI Agent 运行时引擎 (NestJS，:6010)
│   ├── system-service/       # 系统服务 (NestJS，:6004)
│   ├── todo-service/         # 待办服务 (NestJS，:6005)
│   ├── mcp-gateway/          # MCP 工具网关 (NestJS，:6006)
│   ├── content-hub/          # 内容中枢/财经资讯 (NestJS，:6007，原 finnews)
│   ├── upload-service/       # 上传服务 (NestJS，:6008)
│   ├── knowledge-service/    # RAG 知识库 (NestJS，:6011)
│   └── deploy-console/       # 运维控制台后端 (NestJS，:6200)
├── packages/                  # 共享包
│   ├── types/                # TypeScript 类型定义（权限等）
│   ├── shared/               # 共享工具函数与常量（API_TIMEOUT 等）
│   ├── shell-loader/         # 自研微前端加载器（register/mount/unmount）
│   ├── mcp-core/             # MCP 核心框架（声明式 HTTP 适配器）
│   ├── ui/                   # 公共 UI 规范（设计 token + AntD 注册）
│   ├── agent-core/           # @kedouai/agent-core：Agent 核心库（ReAct 引擎）
│   └── kedou-agent/          # Agent CLI（基于 agent-core）
├── ecosystem.config.cjs       # PM2 进程管理配置（web-* 12 个，端口写死）
└── docs/                      # 技术文档
```

## 2. 整体架构

### 2.1 开发环境拓扑

```
   Browser ──────────┐
   portal (:5173) ───┤
   admin (:5174) ────┤  Vite Dev Server（HMR）
   deploy-console ───┘  独立 SPA（6200/console/）
                     │
                     ▼
              ┌──────────────────────┐
              │   Gateway (:6000)    │
              │  /health  → 心跳      │
              │  /api/*   → 代理后端  │
              │  微前端基座 + 静态托管  │
              └───┬───┬───┬───┬───┬──┘
                  │   │   │   │   │
        ┌─────────┘   │   │   │   └─────────┐
        ▼             ▼   ▼   ▼             ▼
     auth:6101    user:6002  ai:6003   ...   content-hub:6007
                                       mcp-gateway:6006
```

### 2.2 生产环境拓扑

**云上架构（2026-09 迁移）**：

- 数据库统一腾讯云 MySQL（`gz-cdb-8y2lp8rt.sql.tencentcdb.com:27241`，8.0.30-txsql，`utf8mb4_0900_ai_ci`）；生产 `NODE_ENV=production` 关闭 TypeORM synchronize，新表靠迁移脚本（`scripts/apply-migrations.sh`）。
- 三台机器：堡垒机（腾讯云轻量，跑 deploy-console 与发布执行）、dev、prod。
- ⚠️ **dev 与 prod 目前共用同一 `web_system` 业务库**（过渡态，正式运营前需拆库）。知识库 `web_system_knowledge`、发布平台库 `web_system_deploy` 均在云上，dev console 与堡垒机 console 共用 `web_system_deploy`。

```
用户浏览器 / 小程序 / WorkBuddy
      │  HTTPS（nginx / local.kedouai.com）
      ▼
┌────────────────────────────────┐
│ 应用层（dev / prod）            │
│  Gateway (:6000)               │
│   ├─ /api/* → 各微服务（:6002~6011, :6200）│
│   ├─ 微前端基座 + 静态托管       │
│   │   static/modules/<key>/<ver>/│
│   └─ /api/mcp、/api/* 代理       │
│  微服务（12 个 pm2 web-*）        │
│  云 MySQL（web_system /         │
│   web_system_knowledge）        │
│  Redis（缓存/会话）              │
└────────────────────────────────┘
       ▲
       │ 发布：工作区 push → 发布目录 git 拉取 → 构建
   堡垒机 deploy-console (:6200)
```

## 3. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | Vue 3 + TypeScript | SPA 应用 |
| **UI 库** | Ant Design Vue 4 | 企业级组件库 |
| **构建工具** | Vite | 快速开发与构建 |
| **状态管理** | Pinia | Vue 3 官方推荐 |
| **路由** | Vue Router | SPA 路由 |
| **后端框架** | NestJS | 企业级 Node.js 框架 |
| **HTTP 服务器** | Express (via NestJS) | 底层 HTTP 处理 |
| **API 代理** | http-proxy-middleware | 请求转发中间件 |
| **MCP 协议** | @modelcontextprotocol/sdk | streamable-http 端点 |
| **数据库** | MySQL + TypeORM | 生产环境持久化 |
| **缓存** | Redis | 会话/令牌缓存 |
| **认证** | JWT | 无状态认证 |
| **包管理** | pnpm workspace | Monorepo 依赖与构建管理 |
| **进程管理** | PM2 | 生产环境进程守护 |
| **反向代理** | Nginx | SSL 终止、域名路由、静态资源 |
| **微信小程序** | UniApp | 跨平台小程序框架 |

## 4. 模块划分

### 4.1 apps/ — 前端应用

| 模块 | 说明 | 技术 | 开发端口 | 生产托管 |
|------|------|------|---------|---------|
| `shell` | 微前端基座（提供 `window.__SHARED__` + 版本 manifest） | Vue3 | — | gateway `public/` |
| `portal` | 少儿教育门户 | Vue3 + AntD + Vite | 5173 | gateway `static/modules/portal/` |
| `admin` | 管理后台 | Vue3 + AntD + Vite | 5174 | gateway `static/modules/admin/` |
| `deploy-console` | 运维控制台（独立 SPA） | Vue3 + Vite | — | deploy-console 后端 `:6200/console/` |
| `mini-app` | 微信小程序（主端） | 原生 + TS | — | 独立上传 |
| `mini-contract` | 微信小程序·合同翻译官 | 原生 + TS | — | 独立上传 |

> 微前端模块（portal/admin）走 `vite build --mode mf` 产出到 `gateway/public/static/modules/<key>/<version>/`，由 gateway manifest 切指针升级/回滚。

### 4.2 servers/ — 后端微服务（12 个 pm2 进程）

| 模块 | 说明 | 端口 | pm2 名 |
|------|------|------|--------|
| `gateway` | API 网关：统一入口 + 代理 + 微前端基座/版本分发 | 6000 | web-gateway |
| `auth-service` | 认证服务：JWT 签发/验证、微信 OAuth | 6101 | web-auth |
| `user-service` | 用户服务 | 6002 | web-user |
| `ai-service` | AI 服务：对话/生图/变变 | 6003 | web-ai |
| `ai-agent` | AI Agent 运行时引擎（ReAct） | 6010 | web-ai-agent |
| `system-service` | 系统服务（配置/素材/字典） | 6004 | web-system |
| `todo-service` | 待办服务 | 6005 | web-todo |
| `mcp-gateway` | MCP 工具网关：声明式 HTTP → MCP 工具 | 6006 | web-mcp-gateway |
| `content-hub` | 内容中枢（财经/AI 资讯，原 finnews） | 6007 | web-content-hub |
| `upload-service` | 上传服务 | 6008 | web-upload |
| `knowledge-service` | RAG 知识库（embedding/检索） | 6011 | web-knowledge |
| `deploy-console` | 运维控制台后端（发布/环境/监控） | 6200 | web-deploy-console |

> 端口全部在 `ecosystem.config.cjs` 写死（防 `pm2 restart --update-env` 漂移污染）。服务清单唯一事实源 = 该文件；未登记的服务会成为孤儿进程（端口被非 pm2 管辖进程占用）。

### 4.3 packages/ — 共享包

| 模块 | 说明 |
|------|------|
| `@web-system/types` | 共享 TypeScript 类型定义 |
| `@web-system/shared` | 共享工具函数与常量（API_TIMEOUT 等） |
| `@web-system/mcp-core` | MCP 核心框架：buildServer / createHttpModule / 声明式 HTTP 适配器 |
| `@web-system/ui` | 公共 UI 规范：设计 token + AntD 组件注册清单 |

## 5. 网关设计

Gateway（:6000）是整个系统的统一入口，负责多类请求分发：

| 分类 | 前缀 | 职责 |
|------|------|------|
| 🔍 健康检查 | `/health` | 服务存活性检测 |
| 🔄 API 代理 | `/api/*` | 转发到各微服务 |
| 🔀 MCP 代理 | `/api/mcp/*` | 转发到 mcp-gateway（含鉴权） |
| 📦 静态资源 | `/assets/*`、`/portal/`、`/admin/`、`/console/`（deploy-console） | 微前端模块 + 运维控制台 SPA 托管 |
| 🌐 SPA 回退 | 无后缀 GET | 返回对应 `index.html` |
| 📚 接口文档 | `/docs`、`/swagger` | Swagger 文档 |

完整的路由映射、代理规则、路径重写见独立文档：

> 📄 [网关 URL 规划](./网关URL规划.md)

## 6. 后端微服务

### 6.1 Auth Service — :6101

- 用户注册/登录、微信 OAuth、小程序登录
- JWT Token 签发与验证
- 依赖：MySQL、JWT Secret

### 6.2 User Service — :6002

- 用户 CRUD、状态管理
- 依赖：MySQL

### 6.3 AI Service — :6003

- AI 对话、生图、变变（bianbian）
- 依赖：外部 AI API

### 6.4 System / Todo / Upload — :6004 / :6005 / :6008

- 系统配置、待办事项、文件上传
- 依赖：MySQL

### 6.5 MCP Gateway — :6006

- MCP streamable-http 端点 `/mcp`、`/mcp/:module`
- 声明式 HTTP 适配器：把后台 REST 接口转成 MCP 工具
- 模块管理 API `/api/modules`（供 deploy-console 调用）
- 依赖：MySQL（模块/工具表）、`@web-system/mcp-core`

### 6.6 Content Hub — :6007（原 finnews）

- 财经资讯采集（新浪/东财快讯）、SimHash 去重、LLM 摘要/情感分析
- 对外提供 5 个 REST 接口：`/api/topics`、`/api/search`、`/api/stock-news`、`/api/sector-hot`、`/api/market-pulse`
- 依赖：MySQL、LLM API

## 9. 部署架构

### 9.1 发布部署（发布目录 + 流水线）

**运行拓扑**：所有服务统一从**发布目录 `~/web_system_release`** 运行（pm2 `web-*`，dotenv 按 cwd 加载发布目录 `.env`）。发布 = 工作区 commit&push → 发布目录 git 拉取 → 构建部署，**不基于当前工作区**。

| 发布对象 | 通道 |
|--------|------|
| 后端服务 + admin/portal 前端 | **发布流水线**（`POST /api/pipelines`，env=local/prod，branch 指定）→ 轮询 jobId 至 succeeded |
| deploy-console 自身（6200） | **传统发布**（`./scripts/publish-deploy-console.sh`，勿走流水线会自杀式 restart 执行者） |

**进程管理**：PM2 管理 12 个微服务进程，配置见 `ecosystem.config.cjs`（端口写死）。

**迁移**：`NODE_ENV=production` 下 synchronize 关闭，新表靠 `./scripts/apply-migrations.sh <local|dev|prod>`（幂等，记 `schema_migrations`）。

> 详细运维手册：`docs/development/local-release-runbook.md`；流水线设计：`docs/development/deploy-pipeline-dev.md`。

### 9.2 本地开发

各服务独立 `pnpm dev` 启动，端口见「8. 端口分配」。前端用 Vite HMR。

## 11. MCP 平台与鉴权

> MCP 平台是 2026-08 新增的子系统：把后台微服务零代码接入 MCP 协议，供 WorkBuddy 等 AI 客户端调用。

### 11.1 组件

| 组件 | 端口 | 说明 |
|------|------|------|
| `mcp-gateway` | 6006 | MCP 工具网关：声明式 HTTP 适配器转 MCP 工具，暴露 `/mcp`、`/mcp/:module` |
| `content-hub` | 6007 | 内容中枢微服务（原 finnews，code_key=`finnews` 保留兼容） |
| `deploy-console` | 6200 | 运维控制台（MCP 平台管理入口，托管 `/console/`） |
| `@web-system/mcp-core` | — | 共享包：buildServer / createHttpModule / HTTP 适配器 |

### 11.2 关键链路

```
WorkBuddy → https://dev.kedouai.com/mcp/finnews → mcp-gateway(:6006)
  → 声明式 HTTP 模块 → https://dev.kedouai.com/api/finnews/* → gateway(:6000)
  → 鉴权 → content-hub(:6007)
```

- `/mcp` 聚合所有启用模块工具；`/mcp/:module` 按 `code_key` 只暴露单模块
- 服务间鉴权（mcp-gateway ↔ gateway）详见独立文档

> 📄 [MCP 服务间鉴权方案](./MCP服务间鉴权.md)
