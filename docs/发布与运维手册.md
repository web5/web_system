# web_system 发布与运维手册

> 更新：2026-08-24 · 目的：统一发布入口，减少权限确认，明确脚本职责

## 一、一键发布（推荐）

**所有发布用一条命令完成**（预检 → 构建 → 部署 → 复检），授权一次跑完全部，不再逐个 ssh/scp 弹确认。

```bash
# 发布到 dev（后端全部 + 前端 portal/admin）
npm run pub:dev

# 发布到 prod（后端全部 + 前端 portal/admin）
npm run pub:prod

# 只发指定目标（后端服务名或前端模块名）
npm run pub:dev -- user todo          # 只发 user/todo 服务
npm run pub:prod -- portal admin      # 只发前端模块
npm run pub:dev -- all                # 全量
```

等价直接调用：
```bash
./scripts/publish.sh dev              # 同 npm run pub:dev
./scripts/publish.sh prod user gateway
./scripts/publish.sh dev portal
```

### 常用环境变量
| 变量 | 作用 |
|---|---|
| `SKIP_CHECK=1` | 跳过预检/复检（只部署） |
| `DRY_RUN=1` | 预览将执行的命令，不真正部署 |
| `DEV_DB_PASSWORD` / `PROD_DB_PASSWORD` | 覆盖默认数据库密码 |

## 三、发布流程说明

```
npm run pub:dev
 └─ publish.sh dev
     ├─ 1. check-env.sh dev        预检：缺失/空值/占位符变量
     ├─ 2. health-check.sh dev     预检：FAIL 服务
     ├─ 3. deploy.sh dev <target>  逐个部署（后端 build+scp+pm2 reload / 前端构建+上传+deploy表）
     └─ 4. health-check.sh dev     复检：部署后全绿
```

### 为什么能减少权限确认
- 所有远程操作（scp/ssh）在**一条命令**内完成，WorkBuddy/终端只需授权一次
- 本机到 dev/prod 已配置 SSH 免密（`~/.ssh/id_ed25519_servers`），`BatchMode=yes` 不弹密码
- 部署脚本自动修复 prod 缺 `@web-system/shared` 链接，避免半路报错中断重试

## 四、发布 checklist（新功能上线时）
1. `npm run pub:dev -- <目标>` 验证 dev
2. `./scripts/health-check.sh dev` 确认全绿
3. `npm run pub:prod -- <目标>` 发布 prod
4. `./scripts/health-check.sh prod` 确认全绿
5. 前端模块发布后：`curl https://kedouai.com/<mod>/ | grep version` 确认 manifest 版本号
