## 五、动作门（每次改 .vue/.wxml/.wxss 前必读）

顺序不可跳：**① 改原型（`apps/<app>/prototype/index.html`）→ ② 同步规格 `specs/**/page-spec*.md` → ③ 过 ux-review-checklist → ④ 用户确认原型（人审节点）→ ⑤ 原型/规格单独 commit 记 sha → ⑥ 落码，UI commit message 必须带 `Proto: <sha>`**。

- 纯视觉微调：原型里记一行「微调豁免」。
- 批量机械改动/紧急修复：`UI_GATE=off`。
- 后端改动（servers/）不在此门内，但改完要同步 release + 编译 + 重启。

## 七、关键坑（前人踩过）

1. 后端服务跑在 release 的 `dist/`，**改 workspace 源码不生效**，必须同步 + 编译 + `pm2 restart`。
2. `packages/agent-core` 的 dist 过期会导致 ai-agent 等编译报 `Property 'ts' does not exist`，先 `cd packages/agent-core && npm run build`。
3. 小程序 chat 页缺 SSE `card` 分支，音乐卡片实时出不来——PC 端 `AiChat.vue` 已自补，别照搬小程序。
4. commit-msg hook 会拦「原型/规格与 UI 源码混入同一 commit」和「Proto 未指向有效原型/规格文件」；merge commit 用 `--no-verify`。
