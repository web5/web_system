# Todo List 需求文档

**版本**: v1.0  
**日期**: 2026-07-03  
**产品**: 变变 · Todo List 模块  
**定位**: 儿童/家长任务管理工具，移动端优先，未来集成小程序

---

## 1. 产品定位

为"变变"产品增加任务管理功能，帮助用户（儿童及家长）管理创意任务、学习计划等。设计风格延续变变品牌（魔法橙 #FF8C42）。

---

## 2. 用户角色

| 角色 | 描述 |
|------|------|
| 儿童用户 | 查看任务、标记完成、查看奖励 |
| 家长用户 | 创建任务、设置奖励、监督完成 |
| 管理员 | 管理所有用户任务（后台） |

---

## 3. 功能需求

### 3.1 核心功能（标准版）

#### F1: 任务管理（CRUD）
- **创建任务**: 标题（必填）、描述（可选）、分类、优先级、截止日期
- **编辑任务**: 修改任务信息
- **删除任务**: 软删除（标记删除，可恢复）
- **查看任务**: 列表视图、详情视图

#### F2: 任务状态管理
- **待完成** (pending): 新创建的任务
- **进行中** (in_progress): 用户开始处理
- **已完成** (completed): 用户标记完成
- **已逾期** (overdue): 超过截止日期未完成
- **已取消** (cancelled): 用户主动取消

#### F3: 分类标签
- 预设分类：🎨 创意、📚 学习、🏃 运动、🎵 音乐、🧩 其他
- 支持自定义分类（未来版本）
- 每个任务可选择多个标签

#### F4: 优先级
- 🔴 高 (high): 紧急重要
- 🟡 中 (medium): 普通任务
- 🟢 低 (low): 不紧急

#### F5: 截止日期
- 日期选择器
- 逾期自动标记
- 临近提醒（未来版本）

#### F6: 任务统计
- 今日完成数
- 本周完成数
- 完成率

---

## 4. 非功能需求

### 4.1 性能
- 页面加载 < 1s（首屏）
- 任务列表滚动流畅（虚拟滚动，> 100 条）
- API 响应 < 200ms

### 4.2 兼容性
- 移动端：iOS Safari 12+、Android Chrome 90+
- 平板：iPad Safari、Android 平板
- 桌面端：Chrome、Firefox、Safari（响应式适配）

### 4.3 安全性
- 用户只能访问自己的任务（行级权限）
- JWT 认证
- 输入验证（防 XSS、SQL 注入）

---

## 5. 数据需求

### 5.1 核心数据实体

**Task（任务）**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| title | String | 任务标题 |
| description | Text | 任务描述 |
| status | Enum | 状态 |
| priority | Enum | 优先级 |
| category | String | 分类标签（JSON 数组） |
| due_date | DateTime | 截止日期 |
| completed_at | DateTime | 完成时间 |
| user_id | UUID | 所属用户 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 删除时间（软删除） |

## 6. 界面需求

### 6.1 设计风格
- **主色调**: #FF8C42（魔法橙）
- **辅色调**: #4ECDC4（天空蓝）
- **背景色**: #FFF8F0（暖白）
- **成功色**: #7ED957（薄荷绿）
- **圆角**: 卡片 24px、按钮 16px
- **风格**: 温暖、明亮、轻盈、童趣

### 6.3 交互设计
- **下拉刷新**: 刷新任务列表
- **上拉加载**: 加载更多任务（分页）
- **滑动操作**: 左滑显示"编辑"、"删除"按钮
- **长按**: 快速标记完成
- **动画**: 任务完成时的庆祝动画（✨ 粒子效果）

## 7. API 需求

### 7.1 端点设计

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | /api/todos | 获取任务列表（分页、筛选） |
| GET | /api/todos/:id | 获取任务详情 |
| POST | /api/todos | 创建任务 |
| PUT | /api/todos/:id | 更新任务 |
| DELETE | /api/todos/:id | 删除任务（软删除） |
| PATCH | /api/todos/:id/status | 更新任务状态 |
| GET | /api/todos/stats | 获取任务统计 |

### 7.2 请求/响应格式
- 统一响应格式：`{ code: 0, data: {}, message: "success" }`
- 分页格式：`{ items: [], total: 0, page: 1, pageSize: 20 }`
