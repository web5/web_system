### 1.1 六个结构性病症（都有实证，不是印象）

| # | 病症 | 实证 | 代价 |
|---|---|---|---|
| 1 | **编号是长出来的，不是设计的** | 无 R7；R6 不在 `scan-rules.sh` 而在 `scripts/ci/changed-packages.sh`；R3 一号两义（TODO/FIXME=error，TEMP/TBD=warn）；R4 一号两义（`@ts-ignore` 与 `: any`） | 报错说「R4 违规」，人得先猜是哪一类 |
| 2 | **同一机制被写成 7 条规则** | R10/R11/R13/R14/R15/R17/R18 共用 `_trailer_check_one`，语义完全一致：`<Key>: pass` 或 `<Key>: <报告路径>` + 报告存在 + `阻塞: N`=0 + `Micro-exempt` 豁免 | 学习成本 ×7，实际机制只有 1 个 |
| 3 | **默认不阻断，但都叫「门禁」** | CI 调用不带 `--strict`，13 条 warning 恒绿 | 「门禁通过」这句话失去信息量 |
| 4 | **开关与实现脱节** | ① `eslint.config.mjs` 10-10 已提交，`--lint` 自 09-22 关到 10-22；② `.githooks/` 曾只有 `commit-msg` 无 `pre-commit`；③ 本机 `core.hooksPath` 曾未设置 | 文档承诺的拦截点，实际不存在 |
| 5 | **观察期机制已停摆** | `gate-observation-log.md` 唯一采集点曾停在 2026-09-25，一个月零采集 | warn→error 永远走不到 |
| 6 | **判据源散在 7 份文档** | 查一条门禁要翻 7 处，且各处口径可能已过期 | 读旧文档会得出错误结论 |

**重写原则**：编号不动（动编号会毁掉历史 commit 里的凭证语义），改为「**机制优先、编号降级为索引**」。新人只需记住 5 类机制（见 02），查具体实现再看本文附录 A。

### 2.1 整改优先级解释

- **P0-1 曾是唯一的真问题**：它让「本地门禁」这个说法整体失真。已于 2026-10-22 关闭。
- **P1-1 修复时挖出了更深的问题**：开关没打开只是表象——`apps/shell` / `apps/deploy-console` / `packages/ui`
  **连 lint 脚本都没有**，即使把 `--lint` 加回去也只覆盖 2/5 工程。补脚本 + 加水位，改动约 20 行，价值远大于「把参数加回来」。
- **P2-1 明确不做**：`tree` 不是任何自动化路径的依赖（CI 用 `diff`、pre-commit 用 `cached`），为它重构行扫描器不划算。

## 3 新增门禁准入标准（防再臃肿）

下一次想加门禁时，按顺序过这 7 条。**任何一条不过，就不许加。**

| # | 准入条件 | 反面例子（真实发生过的） |
|---|---|---|
| 1 | **能用现有 5 类机制表达就不许写新脚本** | 新增一个 `check-xxx.mjs` 去做"commit 须带某某 trailer"，而 `_trailer_check_one` 已经能做 |
| 2 | **必须默认 warning，且带观察期落点** | R11 直接上 error（可接受，因为它拦的是"绕过用户确认节点"，属零容忍；但不能成为惯例） |
| 3 | **触发面必须可枚举** | 写"检测架构是否合理"这类语义判断——机器判不了，最终靠人，必然误报泛滥；或用目录通配糊过去（`packages/ui/*` 把 package.json 也当 UI 源码，改个 lint 脚本就被要求设计评审，2026-10-22 实测） |
| 4 | **必须声明豁免方式 + 滥用判据** | 只给 `--no-verify`，没有可审计的豁免通道 → 人会直接跳过整个流程 |
| 5 | **至少在一层真正阻断，否则只能叫「体检项」** | 上线 5 条 warning 门后宣称"门禁已覆盖"，实际一条没拦 |
| 6 | **判据源必须单一**：文档只索引不复述 | 同一个要求在 3 份文档各写一遍，改一处漏两处（当前 7 份判据源就是这么来的） |
| 7 | **同 PR 更新 01 环节表与本文附录 A** | 加了规则但总表没有 → 半年后没人知道它存在 |

> 补充一条软约束：**新增门禁前先问「能不能不加」**。当前 20 个编号里，真正需要的是 13 个阻断项 + C 类凭证的 7 个触发面。再加之前，先确认它不属于"已有机制的又一个触发面"。
