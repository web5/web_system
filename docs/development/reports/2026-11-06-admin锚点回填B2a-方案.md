## 2. 方案设计

### 2.1 判定口径（先定标准，再谈落点）

一个原型锚点只有三种处置，**不许有第四种「先塞上再说」**：

| 判定 | 条件 | 动作 | 本批数量 |
|---|---|---|---|
| ✅ 回填 | 实现中存在**同语义同位置**的结构 | 实现侧打同名 `data-dr` | **17** |
| 🔧 补实现后回填 | 规格**强制要求**但实现缺失 | 按规格补最小实现 + 打锚点 | **2** |
| ⏸ 阻塞 | 规格要求、但属独立功能批次 | 不动，登记归属批次 | **13** |
| ✕ 撤锚点 | 定稿已不做 / 形态已被取代 | 撤原型锚点 + 就地写判据 + 同步 page-spec | **2**（`empty-cta` / `mutex-conflict-hint`） |

> 「塞锚点」为什么比不填更坏：R11b 会因为锚点集合"一致"而报 INFO，门禁从此认为这块被覆盖了。**假绿的锚点 = 永久沉默的缺口。**

### 9.3 运行时 DOM（T2）—— **本批最有价值的一条**

`a-form-item` / `a-collapse-panel` / `a-card` / `a-alert` / `a-breadcrumb` 全是 `inheritAttrs: false`，
属性**不会**自动落地，全靠组件内部把 `attrs` 展开到某个元素上。只 grep 源码看到 `data-dr` 就算通过 = 假绿。

做法：最小沙箱（vite + 真实组件 + antd 透传探针）+ Playwright 取 `document.querySelectorAll('[data-dr]')`。

| 探针 | 实际落点标签 | 结论 |
|---|---|---|
| `a-breadcrumb` | `<nav>` | ✅ attrs 落根 nav |
| `a-collapse-panel` | `<div class="ant-collapse-item">` | ✅ |
| `a-card` | `<div class="ant-card">` | ✅ |
| `a-form-item` | `<div class="ant-row ant-form-item-row">` | ⚠️ 落**内部 Row**，不是 `.ant-form-item` 根（语义仍在字段行内，可接受，此处留痕） |
| `a-alert` | `<div class="ant-alert">` | ✅ |
| `a-page-header` 的 `#backIcon` | 插槽内 `<span>` | ✅ **但必须先有 `@back`**：`renderBack()` 里 `if (!backIcon \|\| !onBack) return null`——没绑 `@back` 时插槽整个不渲染（本批首次探针即踩到，`detail-back` 差点变成假回填） |
| `a-button`（a-empty 内） | `<button>` | ✅ |
