## 1. 现象

在 **Mac 本地**实例上执行批次①半发布治理对账（盘 ↔ 表 ↔ manifest）时，对账报告误报：

> portal / prod 盘指针 = 单字符 `v`（异常占位版本，疑似半发布 / 盘侧撕裂）。

**结论先行：这是假阳性。** 同期四方实取证（prod 机盘 / dev 控制面库 / 云库 `gz-cdb-8y2lp8rt.sql.tencentcdb.com:27241` / live manifest `https://kedouai.com/__manifest__`）一致为 `b6ec9950`，prod 实际无恙。

## 2. 根因

`EnvArtifactService.readPointer` → `resolveStaticTarget`（`servers/deploy-console/src/.../static-target.ts` 约 63–77 行）：

1. 当 `STATIC_PUBLIC_ROOT_<ENV>` / `STATIC_SSH_TARGET_<ENV>` 未配置时，**静默回落**到 `<RELEASE_WORKSPACE>/servers/gateway/public`——即**运行该进程的机器的本地路径**，无任何告警。
2. Mac 本地 `.env` 没有这两个键 → 在 Mac 上跑对账时，portal@prod 的「盘侧」读到的是 **Mac 本机残留文件**（`~/web_system_release/servers/gateway/public/static/modules/portal/prod/index.js`，2026-11-04 遗留的占位版本 `v`）→ 触发假阳性。
3. live console（dev 服务器）配置了 `STATIC_PUBLIC_ROOT_PROD=/data/web_system_static/public` + `STATIC_SSH_TARGET_PROD=root@<prod 机>`，正式环境不复现。
4. 本机残留文件已于 2026-11-12 清理（备份于 `/tmp`）。

## 3. 一分钟判别法

遇到「对账报 prod 盘指针异常 / 单字符版本」时，按序走：

1. **先确认这次对账在哪个环境执行**——看跑对账的进程所在机器，而不是看对账的目标环境。
2. **在 Mac 本地实例跑的 = 高危假阳性**。此时盘侧数据是本机路径，不可信；直接去 live console 重跑对账再下结论。
3. 确需采信本地跑的结果：检查该实例 `.env` 是否配齐 `STATIC_PUBLIC_ROOT_<ENV>` 与 `STATIC_SSH_TARGET_<ENV>`。**没配齐 → 盘侧读数一律作废**。
4. 交叉取证兜底：prod 机盘、dev 控制面库、云库、live manifest 四方比对；四方一致即 prod 无恙，本地报告按假阳性归档。

## 4. 🔴 硬规约

> **批次①类「盘 ↔ 表 ↔ manifest」对账的验证，必须在 live console 所在的 dev 服务器上触发**（`GET /api/reconcile/pointers?run=1`）。
>
> **禁止在 Mac 本地实例跑盘侧对账。** 确需本地跑，必须先把 `STATIC_PUBLIC_ROOT_<ENV>` / `STATIC_SSH_TARGET_<ENV>` 配齐，否则盘侧静默回落本机路径，输出不可信。

## 5. 附带提醒：本地 seed 库不可作对账依据

Mac 本地 `web_system_deploy@127.0.0.1` 库是 **seed 快照**，与 live 控制面库差异巨大。**对账 / 验证一律以 dev 服务器上的 live 控制面库与云库为准**，本地库不参与任何对账比对。

## 6. 证据与出处

- 台账 #8763 诊断定论（2026-11-12，rd-debugger 一手诊断）：
  - 回落机制：`static-target.ts` 约 63–77 行，`STATIC_PUBLIC_ROOT_<ENV>` / `STATIC_SSH_TARGET_<ENV>` 未配置 → 静默回落 `<RELEASE_WORKSPACE>/servers/gateway/public`。
  - 假阳性源文件：Mac 本机 `~/web_system_release/servers/gateway/public/static/modules/portal/prod/index.js`（2026-11-04 遗留占位版本 `v`），已清理、备份于 `/tmp`。

  - live console 配置：`STATIC_PUBLIC_ROOT_PROD=/data/web_system_static/public`、`STATIC_SSH_TARGET_PROD=root@<prod 机>`。
