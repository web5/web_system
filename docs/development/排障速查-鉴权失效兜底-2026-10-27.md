# 排障速查 · 鉴权失效兜底（401 幂等）

> 来源：#288 登录过期重复 toast 修复（2026-10-27）· 沉淀自 fix/runid-and-toast-idempotent
> 规范：《排障速查规范》v1 · 四要素格式

---

## 背景

多个 axios 实例（每 app 2–3 个）各有独立 401 响应拦截器，各自调 `message.error('登录已过期...')` + `router.push('/login')`。并发 401 时堆叠 5 个 toast + 多次跳转。

---

### 场景：登录过期后弹出多个重复 toast / 多次跳转登录页

判据：
```bash
# 1. 全量扫弹点（应只出现在共享 handleAuthExpired 或统一 key 处）
grep -rn "登录已过期" apps/ --include="*.ts" --include="*.vue"

# 2. 检查是否使用 antd message key 幂等
grep -rn "key.*auth-expired\|key.*'auth'" apps/ --include="*.ts"

# 3. 检查跳转防重（isRedirecting 或等价锁）
grep -rn "isRedirecting" apps/ --include="*.ts"
```
→ 若步骤 1 弹点 > 1 处且步骤 2 无 key → 确认是 401 兜底分散实现问题。

易误判：以为是 antd message 组件 bug 或 CSS 层叠问题——实际上是多个拦截器各自调 message.error，不是单条消息渲染多次。另一个误判：以为只要 router.push 幂等就够了——toast 堆叠是 message 层面的，与路由无关。

适用：全环境（deploy-console / admin / portal 三端均有此模式）

---

### 场景：新写 axios 实例时确认 401 兜底是否已统一

判据：
```bash
# 新实例的响应拦截器是否调用共享 handleAuthExpired（或至少 key 幂等）
grep -A5 "interceptors.response" <新实例文件> | grep -E "message\.error|handleAuthExpired|auth-expired"
```
→ 若 `message.error('登录已过期')` 不带 key 或不走共享函数 → 拒绝合入。

易误判：「我这个实例只有一个，不会重复」——问题不是单实例内重复，是跨实例/跨并发请求的叠加。新实例一旦上线就加入叠加计数。

适用：全环境

---

### 场景：排查某次 401 后跳转了多次登录页

判据：
```bash
# 查看是否有跳转防重锁（isRedirecting / equivalent guard）
grep -n "isRedirecting\|router.push.*login" apps/<app>/src/api/*.ts
```
→ 若 `router.push('/login')` 在拦截器中无防重锁 → 多并发 401 会多次 push。

易误判：以为 Vue Router 的同路由 push 天然幂等就不会有问题——虽然不会真的导航多次，但会触发 `NavigationDuplicated` 警告 + redirect 参数可能不一致，仍应加锁。

适用：全环境（deploy-console 与 portal/ai.ts 已补锁；admin/request.ts 与 portal/request.ts 原有锁）

---

## 修复模式（参考实现）

**toast 幂等**（必选）：
```ts
// ❌ 错误：每个实例各自弹
message.error('登录已过期，请重新登录');

// ✅ 正确：统一 key，antd 同 key 只保留 1 条
message.error({ content: '登录已过期，请重新登录', key: 'auth-expired' });
```

**跳转防重**（有 router.push 的场景必选）：
```ts
let isRedirecting = false;
// ...在 401 handler 内：
if (!isRedirecting) {
  isRedirecting = true;
  setTimeout(() => { isRedirecting = false; }, 60000);
  router.push('/login');
}
```

**终极方案**（沉淀建议，待落地）：将 toast + 跳转 + token 清理抽取为共享 `handleAuthExpired()`，各实例统一调用。
