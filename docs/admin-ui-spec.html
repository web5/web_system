Admin 后台 UI 设计规范

主题：双主题（默认亮色，可切换暗色） 技术栈：Vue 3 + Ant Design Vue 4.2 + CSS Variables 页面数：6 个视图 + 1 个布局 版本：v1.3
概述

Admin 后台支持「亮色 / 暗色」双主题，默认亮色。两种主题共用 #FF8C42 品牌橙，通过 CSS Variables + ConfigProvider algorithm + :deep() 三层覆盖实现动态切换。主题状态由 Pinia store 管理，持久化到 localStorage。

设计特征
维度规范
默认主题亮色（Light）— 白底 #FFFFFF + 橙色 #FF8C42 品牌色
暗色主题纯黑 #000000 底色 + 橙色 #FF8C42 品牌色
卡片背景亮色 linear-gradient(135deg, #FFFFFF, #FAFAFC) / 暗色 linear-gradient(135deg, #141419, #16161C)
阴影策略亮色使用 0 4px 16px rgba(0,0,0,.08) / 暗色用 border: 1px solid rgba(255,255,255,0.06) 替代
全局圆角4px（ConfigProvider borderRadius）
品牌色#FF8C42（JS Token），CSS 变量定义为 #F97316
字体族'Inter', -apple-system, BlinkMacSystemFont, sans-serif
毛玻璃顶栏使用 backdrop-filter: blur(12px)
覆盖方案三层：CSS Variables → ConfigProvider Token + algorithm → :deep() scoped 覆盖
主题切换顶栏右侧太阳/月亮按钮，Pinia store (stores/theme.ts) → data-theme 属性 + algorithm 动态切换
持久化localStorage key theme-store

双主题系统

Admin 后台支持亮色/暗色双主题切换。默认亮色，用户可通过顶栏右侧按钮切换。主题切换通过 data-theme 属性 + Ant Design ConfigProvider algorithm 双通道同步。

主题架构
层机制说明
1. CSS Variables:root 暗色默认 + [data-theme="light"] 亮色覆盖30+ 个语义化变量（surface、text、border、input、table、modal、shadow、chart 等）
2. ConfigProvideralgorithm: theme.darkAlgorithm / theme.defaultAlgorithm动态切换 Ant Design 内部组件主题
3. :deep() 覆盖scoped 样式中 :deep(.ant-xxx)处理 CSS 变量无法覆盖的 Ant Design 组件内部样式
4. Pinia Storestores/theme.ts管理 mode: 'light' | 'dark'，持久化到 localStorage
5. data-theme 属性document.documentElement.setAttribute('data-theme', mode)触发 CSS 变量切换

⚠
文本色不一致：CSS 变量定义 --text-primary: #F8FAFC，但组件中标题实际使用 #F1F5F9。建议统一。
✓

⚠
弹窗风格不统一：UserList Modal 是白底（标题色 #0F172A），BianbianManage Modal 做了完整暗色化。两者风格不一致。
✓

⚠
