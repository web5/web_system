# 合同翻译官 · 贷款场景尺子设计

> 版本：v1.0 · 2026-08-27
> 主题：贷款/消费金融合同的专属分析尺子，聚焦用户真正关心的决策点

## 一、现状：已有 8 个通用尺子偏法务合规

`packages/shared/src/contract/standards/common.ts` 已定义 8 个跨场景尺子：

| 尺子 id | 名称 | 严重度 | 关注点 |
|---|---|---|---|
| `usury-interest` | 利率上限 | danger | 真实年化超 24%/36% |
| `kickback-interest` | 砍头息 | danger | 利息预先从本金扣除 |
| `early-repay-penalty` | 提前还款违约金 | warn | 提前还款收费/锁定 |
| `deposit-cap` | 定金上限 | warn | 定金超 20% |
| `penalty-cap` | 违约金上限 | warn | 违约金超损失 30% |
| `force-bundling` | 强制搭售 | warn | 捆绑会员/附加产品 |
| `auto-renew` | 自动续费 | warn | 自动续费未显著提示 |
| `standard-clause` | 格式条款 | warn | 免责/单方权利条款 |

**问题**：这些尺子偏"合规扫描"，**缺少用户真正关心的"贷款决策点"**。

## 二、新增 3 个贷款专属尺子

放在 `packages/shared/src/contract/standards/scenes/consumer-loan.ts`，归属场景 `consumer-loan` / `car-loan`。

| 尺子 id | 名称 | 关注点（用户视角） |
|---|---|---|
| `repayment-scheme` | 还款方式陷阱 | 识别"先息后本/等额本息/等额本金"，点破前期本金占比低的问题 |
| `monthly-payment-check` | 月供合理性 | 月供占总收入比例过高、期数过长导致总利息翻倍 |
| `prepay-timing` | 提前还款时机 | 算清锁定期后提前还才划算，避免违约金 |

## 三、给每把尺子补"可主张金额"

这是核心付费锚点。给 `LegalStandard` 增加字段：

```ts
/** 可主张金额计算说明 */
refundableAmount?: {
  formula: string;    // 计算公式（占位符可替换成合同真实数字）
  note: string;       // 大白话说明
  example: string;    // 示例
};
```

已有 8 个通用尺子也要补：
- `kickback-interest`：`本金 - 实际到手金额`
- `usury-interest`：`总利息（合同）- 总利息（按 24% 计）`
- `force-bundling`：被强制搭售扣除的费用
- `penalty-cap`：违约金 - 实际损失 30%
- `deposit-cap`：定金 - 标的额 20%
