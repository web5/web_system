# 市场基准库（market-benchmark）

> 供 `contract-benchmark` 工具返回、AI 引用对比的确定性数据源。
> 目的：避免 AI 自由编造"同类贷款利率"。

## 基准数据（初版）

| 贷款类型 | 常见真实年化区间 | 大白话说明 |
|---|---|---|
| 银行消费贷 | 3.4% ~ 12% | 信用好可低至 3.4% |
| 信用卡分期 | 13% ~ 18% | 表面费率低，实际年化高 |
| 消费金融公司 | 15% ~ 24% | 头部平台常见 |
| 购车贷 | 3.5% ~ 9% | 厂商贴息可更低 |
| 小额贷/现金贷 | 24% ~ 36% | 接近或触及红线 |

## 数据治理

- **数据来源**：公开市场数据 / 监管披露（待补充具体引用）
- **更新频率**：建议季度复核
- **维护责任人**：产品 + 法务

## 边界声明
基准为"市场参考区间，非承诺利率"，最终以实际合同为准。
