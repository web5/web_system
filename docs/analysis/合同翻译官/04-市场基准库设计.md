# 合同翻译官 · 市场基准库设计

> 版本：v1.0 · 2026-08-27
> 主题：同类贷款对比的确定性数据源（`contract-benchmark` 工具）

## 一、为什么需要

用户强烈诉求"对比其他贷款有什么优劣势"。但让 AI 自由发挥对比数字不可靠（容易编造）。

**方案**：内置市场基准库（**确定性数据**，代码维护），`contract-benchmark` 工具返回真实区间，AI 只负责引用和话术。

## 二、内置基准（初版）

| 贷款类型 | 常见真实年化区间 | 大白话说明 |
|---|---|---|
| 银行消费贷 | 3.4% ~ 12% | 信用好可低至 3.4% |
| 信用卡分期 | 13% ~ 18% | 表面费率低，实际年化高 |
| 消费金融公司 | 15% ~ 24% | 头部平台常见 |
| 购车贷 | 3.5% ~ 9% | 厂商贴息可更低 |
| 小额贷/现金贷 | 24% ~ 36% | 接近或触及红线 |

## 三、代码结构

`packages/shared/src/contract/standards/benchmark.ts`：

```ts
export interface MarketBenchmark {
  type: string;            // 贷款类型，如"消费贷""购车贷"
  typicalAprRange: string; // "3.4%~12%"
  note: string;            // 大白话说明
}

export const MARKET_BENCHMARKS: MarketBenchmark[] = [
  { type: '消费贷（银行）', typicalAprRange: '3.4%~12%', note: '信用好可低至 3.4%' },
  // ...
];
```

`servers/ai-agent/src/contract/tools/contract-benchmark.tool.ts`：根据贷款类型返回对应基准区间 + 大白话说明。**纯确定性，无 LLM**。

## 四、数据治理（关键）

基准数据**不能变成"AI 拍脑袋数据"**，必须有：
- **数据来源**：在文档中标注来源（如公开市场数据、监管披露）
- **更新频率**：建议季度复核
- **维护责任人**：产品 + 法务

`contract-benchmark` 返回结果标注"市场参考区间，非承诺利率，以实际合同为准"。

## 五、AI 引用方式

AI 拿到基准后，话术范式：

```text
你的真实年化 25.06%，而银行消费贷常见区间 3.4%~12%、消费金融公司 15%~24%，
你的成本明显偏高，接近 24% 法定保护线，可主张调整。
```
