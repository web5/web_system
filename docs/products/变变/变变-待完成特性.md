## 一、分享功能

### 1.1 社交分享（高优先级）

当前 `Result.vue` 只有「保存到相册」（下载到本地），缺少社交分享能力。

| 分享渠道 | 描述 | 技术方案 |
|---------|------|---------|
| 微信朋友圈 | 生成分享海报，引导用户保存后手动发朋友圈 | 使用 Canvas 生成带二维码的海报图片 |
| 微信好友 | 调用微信 JS-SDK 分享（需公众号/小程序绑定） | 接入 `weixin-js-sdk`，配置 `updateAppMessageShareData` |
| 复制链接 | 生成可分享的 H5 链接 | 后端需提供作品详情 API + 作品 ID 关联 |
| 下载分享图 | 一键生成带品牌水印的分享图片 | Canvas 合成（原画 + AI 角色 + 品牌 Logo + 二维码）|

### 1.2 分享海报生成（中优先级）

在结果页增加「分享」按钮，点击后生成一张精美海报：

```
┌──────────────────────────┐
│  ✨ 我变出来的！          │
│                          │
│   ┌─────┐   ┌─────┐     │
│   │原画  │   │角色  │     │
│   └─────┘   └─────┘     │
│                          │
│   把想象，变出来           │
│                          │
│   ┌──────────────────┐   │
│   │  [二维码]         │   │
│   └──────────────────┘   │
│   扫码也来变一个吧～       │
│                          │
│   [保存图片] [微信好友]    │
└──────────────────────────┘
```

**所需组件：**
- `SharePoster.vue` — 海报生成组件（使用 `html2canvas` 或 Canvas API）
- `ShareSheet.vue` — 分享面板组件（底部弹出式，类似微信分享菜单）

### 1.3 后端支持

| API | 方法 | 说明 |
|-----|------|------|
| `POST /bianbian/share/generate` | 生成分享链接/短链 | 返回分享 URL |
| `GET /bianbian/share/:id` | 根据分享 ID 获取作品详情 | 供外部访问 |

## 二、服务端持久化（中优先级）

当前所有数据存储在 `localStorage`，存在以下问题：

| 问题 | 影响 |
|------|------|
| 换设备丢失 | 用户无法在不同设备间查看作品 |
| 清除浏览器缓存丢失 | 用户误操作后历史作品全部丢失 |
| 最多 20 条限制 | 容量有限，且无云端备份 |

### 2.1 后端接口

| API | 方法 | 说明 |
|-----|------|------|
| `POST /bianbian/records/save` | 保存作品到服务端（需登录） | 关联 userId |
| `GET /bianbian/records` | 获取云端作品列表 | ✅ 已有 |
| `DELETE /bianbian/records/:id` | 删除云端作品 | ✅ 已有 |
| `POST /bianbian/records/sync` | 将本地 localStorage 作品同步到云端 | 首次登录时触发 |

### 2.2 登录联动

- 未登录：使用 localStorage（现状）
- 登录后：自动将 localStorage 作品同步到服务端
- 登录后：优先从服务端加载作品列表，localStorage 作为缓存
