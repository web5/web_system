# 变变 & 画板 — 素材升级方案

> 文档版本：v1.0  
> 更新日期：2026-07-19

---

## 一、现状分析

### 1.1 当前问题

| 页面 | 素材现状 | 具体问题 |
|------|---------|---------|
| **变变（Create.vue）** | 19 个 emoji + 6 种纯色背景 | emoji 在不同平台渲染差异大、风格不统一、偏小偏淡、对儿童吸引力不足 |
| **画板（Draw.vue）** | 无素材库，纯 Canvas 绘画 + AI 文生图 | 缺少贴纸/装饰元素，低龄儿童绘画门槛高，只能靠打字描述 |
| **后端素材 API** | ai-service 硬编码 19 个 emoji | 素材与前端高度耦合，新增素材需改代码 |
| **管理后台** | system-service 有完整 CRUD + 数据库 `bianbian_materials` 表 | **已有能力未利用**，种子数据仍是 emoji |

### 1.2 已有基础设施（可直接利用）

- `bianbian_materials` 表 `type` 字段已支持 `emoji / svg / color`
- `system-service` 有完整的素材 CRUD API（增删改查、批量排序、启用/禁用、分页筛选）
- 管理后台已有素材管理界面（可上传/编辑/预览素材）
- 前端已接入 `GET /api/bianbian/materials` 接口

---

## 二、整体方案

分四个阶段迭代，每阶段可独立上线：

```
阶段一 [1-2天] SVG 图标替换 emoji
    ↓
阶段二 [3-5天] AI 生成主题素材包
    ↓
阶段三 [2-3天] 画板增加贴纸素材层
    ↓
阶段四 [持续] 素材运营流程 + 管理后台增强
```

---

## 三、阶段一：SVG 图标替换 emoji（高优先级）

### 3.1 目标

用风格统一的开源 SVG 图标替换 emoji，做到**立竿见影的视觉提升**，纯前端改动，不依赖设计资源。

### 3.2 方案选择

| 方案 | 推荐度 | 说明 |
|------|--------|------|
| **Tabler Icons** | ⭐ 首选 | 4000+ 图标，统一 2px 描边风格，MIT 许可，支持按需加载 |
| Lucide | 备选 | 类似 Feather，社区活跃，图标数较少 |
| Heroicons | 备选 | 纯 SVG，风格统一，数量有限 |

推荐 **Tabler Icons** 原因：
- 数量丰富（4000+），能覆盖动物/自然/食物/交通/形状等儿童场景
- 统一的 2px 描边风格，拼贴后视觉协调
- MIT 许可，可商用
- 支持 tree-shaking，可按需打包

### 3.3 精选素材清单

从 Tabler Icons 精选约 60 个适合儿童的图标，按分类：

| 分类 | 图标 | 数量 | 适用场景 |
|------|------|------|---------|
| **动物** | cat/dog/rabbit/bear/panda/fox/unicorn/dinosaur/bird/fish/butterfly/bee | 12 | 变变 + 画板贴纸 |
| **自然** | sun/moon/star/cloud/rainbow/flower/tree/mushroom/leaf/snowflake/fire/water | 12 | 变变 + 画板贴纸 |
| **食物** | cake/ice-cream/candy/apple/watermelon/cookie/pizza/donut | 8 | 变变贴纸 |
| **交通** | rocket/airplane/car/train/ship/bicycle/helicopter | 7 | 变变贴纸 |
| **物品** | gift/crown/balloon/music/lightbulb/key/umbrella/book/camera/heart | 10 | 变变贴纸 |
| **形状** | circle/square/triangle/diamond/star/heart/arrow/hexagon | 8 | 变变形状 |
| **背景** | 渐变天空/星空/森林/海洋/彩虹/花园主题 | 6 | 变变背景 |

### 3.4 实施步骤

#### 3.4.1 安装 Tabler Icons

```bash
cd apps/portal
npm install @tabler/icons-vue
```

#### 3.4.2 定义素材映射表

创建 `apps/portal/src/config/bianbian-materials.ts`：

```typescript
import {
  IconCat, IconDog, IconRabbit, IconBear, IconPanda, IconFox,
  IconSun, IconMoon, IconStar, IconCloud, IconRainbow, IconFlower,
  // ... 按需导入
} from '@tabler/icons-vue';

/** 素材定义：图标组件 + 元数据 */
export const SVG_MATERIALS: MaterialSVGDef[] = [
  // 动物
  { id: 'svg-animal-1', category: 'sticker', name: '小猫', component: IconCat, color: '#FF8C42' },
  { id: 'svg-animal-2', category: 'sticker', name: '小狗', component: IconDog, color: '#4ECDC4' },
  // ...
];
```

> **注意**：由于 `@tabler/icons-vue` 组件在循环中动态渲染较复杂，更推荐方案二：**直接使用 SVG 字符串**。

#### 3.4.3 推荐方案：SVG 字符串（更简单）

创建 `apps/portal/public/materials/svg/` 目录，存放精选的 SVG 文件。

或直接在代码中内联 SVG 字符串：

```typescript
// apps/portal/src/config/bianbian-materials.ts
export const SVG_MATERIALS: MaterialItem[] = [
  {
    id: 'svg-animal-1',
    category: 'sticker',
    name: '小猫',
    // Tabler Icons 的 SVG path
    svg: '<svg viewBox="0 0 24 24" fill="none" stroke="#FF8C42" stroke-width="2"><path d="..."/></svg>',
  },
  // ...
];
```

#### 3.4.4 前端渲染改造

**Create.vue 改动**：

1. `MaterialItem` 接口增加 `type: 'emoji' | 'svg' | 'color'` 和 `svg?: string` 字段
2. 素材列表渲染（模板第 32 行）增加 SVG 渲染分支：

```vue
<!-- 素材列表项 -->
<button class="material-item" @click="addMaterial(item)">
  <!-- emoji 素材 -->
  <span v-if="item.type === 'emoji'" class="material-emoji">{{ item.icon }}</span>
  <!-- SVG 素材 -->
  <span v-else-if="item.type === 'svg'" class="material-svg" v-html="item.svg"></span>
  <!-- 颜色素材（背景） -->
  <span v-else-if="item.type === 'color'" class="material-color" :style="{ background: item.icon }"></span>
  <span class="material-label">{{ item.name }}</span>
</button>
```

3. 画布元素渲染（模板第 61 行）增加 SVG 渲染分支：

```vue
<!-- 画布上的元素 -->
<!-- emoji -->
<span v-if="el.type === 'emoji'" class="element-content" :style="{ fontSize: el.fontSize + 'px' }">
  {{ el.content }}
</span>
<!-- SVG -->
<span v-else-if="el.type === 'svg'" class="element-svg" :style="{ width: el.fontSize + 'px', height: el.fontSize + 'px' }"
  v-html="el.content">
</span>
<!-- 颜色背景 -->
<div v-else-if="el.type === 'color'" class="element-bg" :style="{ background: el.content }"></div>
```

4. `CanvasElement` 接口增加 `type` 字段：

```typescript
interface CanvasElement {
  id: string;
  content: string;
  type: 'emoji' | 'svg' | 'color';
  x: number;
  y: number;
  scale: number;
  rotation: number;
  fontSize: number;
}
```

5. `addMaterial()` 方法根据素材类型设置正确的 `type` 字段

#### 3.4.5 后端改动

**ai-service BianbianController.getMaterials()**：从 system-service 的 `bianbian_materials` 表读取，而不是硬编码。可通过 HTTP 调用 system-service 的 admin API，或让 ai-service 直连数据库。

**简化方案**：ai-service 直接查询 `system-service` 的数据库（同库不同表），或让 ai-service 新增一个查询素材的 RPC 接口。

> **建议**：当前 ai-service 和 system-service 是独立数据库，最佳方案是让 ai-service 通过 HTTP 调用 `GET http://system-service:3004/admin/bianbian/materials?enabled=true` 获取启用中的素材列表。

### 3.5 阶段性成果

- 素材从 19 个 emoji → 60+ 统一风格的 SVG 图标
- 背景从 6 种纯色 → 6 种主题渐变背景
- 管理后台可动态上架/下架/排序素材
- 视觉一致性大幅提升

## 四、阶段二：AI 生成主题素材包（中优先级）

### 4.1 目标

用 AI 批量生成专属风格的贴纸 PNG/SVG，形成"变变"品牌辨识度。

### 4.2 生成流程

```
Step 1: 写提示词模板
  → "cute cartoon {subject} sticker, thick line, flat design, 
     warm color palette (#FF8C42 #4ECDC4 #FFF8F0), white background, 
     kids friendly, simple shapes, no shading"

Step 2: 批量生成（DALL-E 3 / Midjourney / 通义万相）
  → 每批 4 张，一个主题包 12-20 张

Step 3: 人工筛选 + 去底
  → 用 remove.bg / ClipDrop 去背景
  → 转成透明 PNG 或 SVG 描边

Step 4: 上传到管理后台
  → 通过 system-service 的 POST /admin/bianbian/materials 入库
  → type='svg', content='素材图片 URL'
```

### 4.4 技术实现

**后端存储方案**：

```typescript
// 素材入库示例
{
  name: '魔法小猫',
  category: 'sticker',
  content: '/uploads/materials/magic-cat.png',  // 素材图片 URL
  type: 'svg',  // 实际是 PNG，但用 svg 类型表示"图片素材"
  icon: '🐱',
  source: 'custom',
  sortOrder: 1,
  enabled: true,
  tags: '猫,动物,魔法,sticker',
}
```

**前端渲染**：

```vue
<!-- 画布上的图片素材 -->
<img v-else-if="el.type === 'image'" :src="el.content" class="element-image"
  :style="{ width: el.fontSize + 'px', height: el.fontSize + 'px' }" />
```

**文件上传接口**：管理后台需要支持素材图片上传，建议：

| API | 说明 |
|-----|------|
| `POST /admin/bianbian/materials/upload` | 上传素材图片，返回 URL |
| 存储位置 | `servers/gateway/public/uploads/materials/`（由 gateway 静态服务） |

## 五、阶段三：画板增加贴纸素材层（中优先级）

### 5.1 目标

Draw.vue 的"自由绘画"模式增加贴纸装饰功能，复用变变的素材库。

### 5.2 功能设计

**交互方式**：

```
┌─────────────────────────────────────────┐
│  ✏️ 画笔  │  🎨 填充  │  ⭐ 贴纸  │   ← 新增"贴纸"工具
├─────────────────────────────────────────┤
│                                         │
│   [全部] [动物] [自然] [食物]           │  ← 素材分类 tab
│                                         │
│   ┌───┐ ┌───┐ ┌───┐ ┌───┐            │
│   │猫 │ │狗 │ │兔 │ │熊 │            │  ← 素材横向滚动
│   └───┘ └───┘ └───┘ └───┘            │
│                                         │
│  ┌─────────────────────────────────────┐│
│  │                                     ││
│  │       Canvas 画布                   ││
│  │         (贴纸可拖拽/缩放/旋转)       ││
│  │                                     ││
│  └─────────────────────────────────────┘│
│                                         │
│  [清空] [撤销] [保存]                   │
└─────────────────────────────────────────┘
```

### 5.3 技术实现

**Draw.vue 改造**：

1. 增加 `activeTool`：`'brush' | 'eraser' | 'sticker'`
2. 选中"贴纸"时，显示素材面板（复用变变的 `loadMaterials()`）
3. 点击贴纸后，在 Canvas 上创建一个**覆盖层元素**（使用绝对定位的 HTML 元素叠加在 Canvas 上，或直接在 Canvas 上绘制）
4. 贴纸元素支持拖拽、缩放、旋转（复用 Create.vue 的拖拽逻辑）

**推荐方案**：使用 **HTML 覆盖层**（与 Create.vue 一致），而非在 Canvas 上绘制。原因：
- 复用已有拖拽/缩放/旋转逻辑
- 贴纸是固定图片，不需要 Canvas 绘制
- Canvas 绘制需要额外实现选中/拖拽状态管理

```vue
<!-- Draw.vue 模板新增 -->
<div v-if="activeTool === 'sticker'" class="material-panel">
  <div class="material-tabs">
    <button v-for="tab in materialTabs" ...>{{ tab.label }}</button>
  </div>
  <div class="material-strip">
    <button v-for="item in filteredMaterials" @click="addSticker(item)">
      <span v-html="item.type === 'svg' ? item.svg : item.icon"></span>
    </button>
  </div>
</div>

<!-- 画布上的贴纸覆盖层 -->
<div class="sticker-layer" v-if="stickers.length > 0">
  <div v-for="stk in stickers" class="sticker-item"
    :style="{ left: stk.x + 'px', top: stk.y + 'px', transform: `scale(${stk.scale}) rotate(${stk.rotation}deg)` }"
    @mousedown="startDragSticker(stk, $event)">
    <img v-if="stk.type === 'image'" :src="stk.content" />
    <span v-else-if="stk.type === 'svg'" v-html="stk.content"></span>
  </div>
</div>
```

### 5.4 阶段性成果

- 画板从"只有画笔" → "画笔 + 贴纸 + AI 生成"三种创作方式
- 贴纸素材与变变共享同一个素材库，一次上传双端可用
- 低龄儿童不需要会画画也能创作出好看的作品

## 八、风险与注意事项

| 风险 | 影响 | 应对方案 |
|------|------|---------|
| SVG 图标颜色无法自定义 | 素材颜色单一 | Tabler Icons 支持 `stroke` 和 `fill` 属性动态设置 |
| 图标风格偏"工具感"不够童趣 | 儿童不喜欢 | 优先选择 Tabler 中圆角/可爱风格的图标；阶段二用 AI 生成弥补 |
| AI 生成素材风格不一致 | 视觉杂乱 | 固定提示词模板 + 同一模型 + 同一风格参考图 |
| 素材去底质量差 | 边缘锯齿/白边 | 使用专业工具 remove.bg / ClipDrop API |
| 画板贴纸层与 Canvas 绘制层级冲突 | 交互异常 | 贴纸使用 HTML 覆盖层，始终在 Canvas 之上 |
