# 合同翻译官 · 整体功能流程图

> 版本：v1.0 · 2026-08-27
> 覆盖：小程序页面流、AI 处理链路、Agent 编排、OCR 一体化、登录鉴权、架构要点

---

## 一、产品全流程总览（用户视角）

```
  首页(主入口) ──► 上传页 ──► 解读中(4步) ──► 结果页(风险报告)
     │                │          │              │
  一键上传       拍照/相册/文件   进度动画     结论+风险信号列表
  场景科普       或粘贴/示例      AI思考中提示  +法律依据+3步操作
  免责声明            │              │              │
       ▲             ▼              ▼              ▼
  我的 ──┴── 历史记录 ◄──┘         保存报告 ──► 可再次查看
```

页面结构：
- **首页**：一键上传合同 + 场景科普卡（消费贷/购车/保险/租房）+ 免责声明
- **上传页**：拍照 / 相册 / 文件 + 文本粘贴 + 示例样本 + 场景选择
- **解读中**：4 步进度动画（识别 → 判断类型 → 测算 → 出报告）+ "AI 思考中"动态提示
- **结果页**：健康指数 + 一句话结论 + 风险信号列表（按严重度）+ 法律依据 + 3 步操作 + 术语解释 + 免责声明
- **历史 / 我的**：记录查看、隐私/免责说明

## 二、核心 AI 处理链路（技术视角）

```
┌──────┐   ┌──────────┐   ┌──────────┐   ┌──────────────┐
│小程序 │──►│ gateway  │──►│ ai-agent │──►│ agent-core   │
│      │   │  (6000)  │   │  (6010)  │   │  (ReAct 引擎) │
└──────┘   └──────────┘   └──────────┘   └──────────────┘
  JWT         nginx 反代    鉴权+编排        工具调度
  登录     local.kedouai    3 个 Tool 调用   多轮 LLM
```

- 小程序经 **nginx（local.kedouai.com）→ gateway → ai-agent**
- 全程 SSE 流式返回（进度 + 工具调用 + 最终报告）
- 鉴权在 gateway/ai-agent 层统一校验 JWT

## 三、Agent 编排流程（核心，3 个工具）

```
        用户上传合同文本(OCR清洗后/粘贴)
                    │
                    ▼
        ┌─ contract-cleaner ◄── 来自OCR时先AI清洗噪声
        │    (LLM删除页眉/表格/状态栏)
        │              │
        │              ▼
        ├─ contract-rule ────► 法定标准库匹配(确定性规则)
        │    (砍头息/利率/违约金/搭售...)
        │              │
        │              ▼
        └─ contract-irr ─────► IRR精确测算(纯函数,100%准)
             (真实年化/总利息/实际到手)
                    │
                    ▼
            LLM生成结构化风险报告
         (风险信号+法律依据+3步+术语)
                    │
                    ▼
             SSE流式返回 → 小程序展示
```

工具职责：
| 工具 | 类型 | 职责 |
|------|------|------|
| `contract-cleaner` | AI(LLM) | 清洗 OCR 噪声，输出纯净条款 |
| `contract-rule` | 确定性规则 | 标准库扫描，识别风险信号 |
| `contract-irr` | 纯函数 | 精确测算真实年化利率 |

> 设计原则：**能用规则算的绝不用 AI 算**。规则判定（标准库）与计算（IRR）是确定性、可测试的；AI 只做"清洗"和"生成话术"。

## 四、OCR 一体化流程

```
  拍照/相册选图 → 腾讯云OCR识别(GeneralBasicOCR)
        │
        ▼
   原始文本(含13:30/5G@24/表格等噪声)
        │
        ▼
   LLM清洗(Cleaner) → 纯净合同条款
        │
        ▼
   填充到textarea(用户看到干净文本)
        │
        ▼
   进入 Agent 分析
```

- OCR 识别 + LLM 清洗整合在 `ai-agent /ocr/recognize` 一个接口
- 用户看到/分析的是**清洗后的纯净文本**，无页眉页脚污染

## 五、登录鉴权流程

```
  小程序启动 → wx.login()拿code
        │
        ▼
  POST /api/auth/miniprogram-login
        │
        ▼
  auth-service → 微信jscode2session(换openid)
        │
        ▼
  生成JWT → 小程序存token → 后续请求带Authorization
        │
        ▼
  ai-agent AuthGuard → auth-service /auth/verify 校验
```

## 六、数据 / 架构要点

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | 微信小程序 | 6 页面 + 底部 Tab |
| 网关 | gateway(6000) + nginx | `/api/*` 代理 + 鉴权透传 |
| AI编排 | ai-agent(6010) | 复用 agent-core，3 个工具 |
| 模型 | DeepSeek(主) + Hy3(备) | tool-calling 稳定 |
| 规则 | `packages/shared` 标准库 | 10 个法定尺子，确定性 |
| 计算 | `packages/shared` IRR | 纯函数，100% 准确 |
| OCR | 腾讯云 GeneralBasicOCR | + LLM 清洗 |
| 存储 | MySQL + Redis | 用户 / 鉴权 |
